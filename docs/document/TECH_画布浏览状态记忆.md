# 画布与目录展开状态记忆

2026-10-28，实现与本地验证记录；实际生产版本以受控发布结果为准。

问题：`folded` 和 `directoryOpen` 只存在 React 页面内存，身份初始化时清空；现有浏览空间记忆仅保存当前空间，因此刷新、离开重进都会恢复默认展开。

修复：使用独立的 `browsingState.ts` 管理本浏览器偏好，按账号和组织隔离，在记录中按空间分组。画布折叠集合、侧边栏明确的展开和关闭（包含项目目录）分别保存，取得当前有权访问的 scene 后一起恢复。只记 ID 与布尔状态，不保存原文、不授予权限、不修改共享节点数据、不调用知识写命令。其他用户的视图不受影响。

恢复时过滤已删除、跨空间或无权访问的 ID；浏览器记录损坏或禁用时退回可用的默认浏览行为。仅浏览状态变化时保存，不随拖动画布的坐标帧重复写入。搜索定位仍按原行为展开目标祖先；对话来源链接也只展开需要的祖先，保留无关分支的折叠。

浏览器退出登录逻辑只删除认证与会话缓存，不删除此偏好；同账号同团队重新登录后可以恢复。不同浏览器、设备或清除站点数据不保证同步，本次不新增服务器偏好存储。

验证：修复前新增的页面重进用例 2 项失败；修复后通过。覆盖展开与关闭、画布与目录独立、项目目录、递归子目录、不同账号/团队、原地身份切换、多项目、过期 ID、无权访问、非法记录与存储异常，并运行完整画布回归。无需数据库迁移；回滚本次前端代码即可，原件与知识内容不变。

实际结果：画布 343 项、状态存储 10 项，共 353 项通过；相关 ESLint、TypeScript 检查与生产构建通过。退出登录路径已核对，不清除此偏好。
