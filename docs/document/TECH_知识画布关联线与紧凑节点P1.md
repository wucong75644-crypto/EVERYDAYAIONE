# 知识画布：关联线完整几何编辑与紧凑节点 P1

状态：本地实现与验证，未部署。接续同一知识画布任务工作树。

## 行为与完成条件

- 单选一个主题后点关联线进入起线模式，预览随指针移动；点已有节点建立关联，点空白处在松手坐标创建浮动主题并连接。双选直接连接保留。Esc、失焦和右键取消未完成起线。
- 浮动主题的 parent_id 为 null，不改变原树层级；创建主题和连线是一个保存/历史步骤。立即进入原位改名，取消改名保留已经创建的主题。
- 端点能在原主题边缘任意调整，也能拖到其他主题，空白处则创建浮动主题并重连；保留同空间、禁止自连与重复线、权限和容器版本检查。
- 两端分别有独立控制点与辅助线。拖动实时预览，松手一次保存，Esc/指针取消回到原形。方向键微调、Shift 加大步长、Home 恢复自动控制；端点方向键沿边缘移动。键盘保存后恢复当前控制点焦点。
- 主题默认按标题、局部字号、图片/媒体和标注内容紧凑显示。长标题在自动宽度上限换行，显式多行保留。已有手动宽度不覆盖。宽度可从 80–800 调整，双击宽度柄或 Home 清除显式宽度，恢复按内容适应。
- 展开编辑、文件等操作移到选中后的浮动工具条；选择与取消选择不改变卡片尺寸。图片缩放柄、媒体编辑入口仅选中时出现，内容仍可浏览。
- 新几何编辑即时跟手，不额外增加自动动画；定位与撤销沿用现有减少动态效果路径。Mac Cmd+Z/Shift+Cmd+Z、Windows Ctrl+Z/Ctrl+Y/Ctrl+Shift+Z 沿用统一历史。

## 任务地图与实现

`KnowledgeCanvas` 工具条 → `useCanvasConnection` 起线/重连预览 → 已有 connect/reconnect_relation 或新增 create_relation_topic → 统一 kb_canvas_command 事务 → refresh/历史定位。

`relationGeometry` 支持相对边缘锚点、相对两端的控制向量；渲染与重连预览共享曲线计算，缩放时转换同一组数值。`CanvasRelations` 提供两端拖动与键盘控制，保存完整 appearance，保留文字与另一端。

`topicEditing.topicWidth/topicSize` 提供虚拟节点尺寸，浏览器通过实际字体测量文字；真实节点仍用 DOM 尺寸。`mapNodeStyle`、批量创建、插入父主题、内容排布和拖动共用紧凑度量。正文与文件入口复用画布外的节点工具条，避免选中后改变排布。

只新增 **326_knowledge_relation_geometry.sql**，不修改已应用的旧迁移。新增 create_relation_topic 事务内写主题、初始版本、画布节点、关联线、事件与幂等回执，统一历史同时快照；写失败全事务回滚。修改原端点的锚点也递增容器版本，重连与锚点保存为同一历史步骤。appearance 新增 source/target_anchor（边缘归一化坐标）和 source/target_control（相对对应端点向量）。默认缺省字段省略，旧关联线及复制快照保持兼容。
