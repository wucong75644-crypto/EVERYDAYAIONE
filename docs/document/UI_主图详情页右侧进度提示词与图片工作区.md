# 主图／详情页右侧工作区

日期：2026-10-09。状态：本地已实施并完成布局与交互回归，未提交部署。

## 1. 设计依据

以本轮用户提供的两张截图为依据：左侧是固定设置与产品输入；右侧是连续结果区域；每张图片上方有可点击的“图片任务详情”。

本记录替代此前方案中独立规划确认页、再次点击确认生成、强制标题／副标题编辑的建议。现有卖点与三阶段提示词规则沿用。

## 2. 固定布局

- 左侧保留截图的设置顺序、上传和需求区、底部“开始生成”；【最新修正】“生成数量”和“提示词模型”放在同一行，数量在左、模型在右；选项 Kimi／Gemini，新草稿默认 Kimi。
- 【最新修正】复用原有合并输入组件：五列缩略图、原需求输入框，底部“上传图片／工作区／AI 帮写”和图片计数。上传与工作区继续加入产品图，已有参考图仍按原身份恢复；不增加独立产品图／参考图上传区、可见的需求标签或上方 AI 按钮。
- 已保存项目恢复用户此前的模型选择；默认 Kimi 不可用时明确提示，用户可主动选 Gemini，不静默切换。
- 【修改】顶部“默认”模式显示生成数量控件，值为“14张”；“生成数量”标签右侧同一行显示“7张主图＋7张详情”。该模式实际生成两组各 7 张，不只修改显示文字。
- 【修改】取消顶部模式说明小字；“默认／主图／详情图”共用相同的字段行、控件高度和间距，模式切换不增删数量行，不改变上传区、模型选择或开始按钮的位置。
- 数量标签与右侧组成说明采用固定高度且不换行的一行，单类模式不使用该说明时保留行高；下拉菜单浮层展开，不撑高表单。仅交互内容变化，外围布局不随焦点、选中态或模式变化移动。
- 右侧空闲时保留输入引导；开始后内容顶部对齐，不再让进度或长提示词始终居中。
- 桌面保留左右两栏；右侧长内容可滚动；窄屏上下排列且不横向溢出。
- 沿用当前产品圆角、颜色、间距和文字层级，不增加装饰性面板。

## 3. 右侧连续状态

| 状态 | 可见内容 | 转换行为 |
| --- | --- | --- |
| 正在分析 | 模型名称及真实阶段：商品分析／视觉方向／生成提示词 | 显示执行、等待和错误，已完成阶段保持可见；不伪造百分比 |
| 提示词可用 | 按用途、序号展示完整生图提示词，可展开和复制 | 不要求另开确认页；后端自动继续生图 |
| 图片任务受理 | 提示词自动折叠为摘要，下方出现对应数量占位符 | 提示词仍可重新展开；每张上方出现“图片任务详情” |
| 生成中 | 稳定位置的占位符，附排队／生成等真实状态 | 每张完成后原位替换，不能按返回顺序重新排列 |
| 部分失败 | 已完成图保留，失败位置显示已有失败占位和错误 | 可重试失败张，保持其用途和序号 |
| 生成完成 | 结果图及上方任务详情，提示词摘要仍保留 | 可预览、下载与查看实际执行提示词 |
| 未能受理生图 | 提示词与明确错误保持可见 | 不将提示词提前隐藏，不显示虚构任务 |

提示词显示的是校验、组装和保存后的可执行正文。若自动续接很快，展开浏览及任务详情仍可随时查看，不人为延时。

## 4. 主图与详情分组

右侧有两种任务时分为“主图”和“详情图”，各组独立显示进度、提示词摘要、数量、占位符和结果。只有一种任务时只显示该组。

同类不同轮次保持轮次归属，重试仍属于原图片位置。分组来自任务配置。【修改】用户已明确“默认”模式为 14 张，其中 7 张主图、7 张详情；默认模式右侧显示两组各 7 个位置。单类模式只显示对应组，沿用该模式数量。

【最新修正】主图在上、详情图在下，各自标题／边框之间增加明确分隔线。两组采用同一自动排列网格，复用聊天 `getImagePlaceholderSize('1:1')` 的180px基准宽度；按容器宽度自动换列，空间不足180px时等比缩小。同屏横向宽度相同，高度按各自实际目标比例计算，保持顺序，不用瀑布流混排。生成中、完成与失败都使用同一列宽，完整显示结果；当前生图比例参数沿用项目设置，本次仅调整显示。

## 5. 任务详情交互

直接沿用用户截图中的入口和现有弹窗：可在排队、生成及完成时打开，查看服务器实际执行提示词、比例／清晰度、原始参考图及状态与费用。

每张图关联自己的任务，点击不能打开整组或另一张图的提示词；重试版本可继续沿用已有比较能力。尚未创建真实图片任务时不显示可点击的假详情入口。

占位、失败、结果、预览、下载和任务详情保持与现有图片能力一致。页面只组织布局和分组，不再设计另一套详情弹窗。

### 批量下载（本轮新增）

右侧顶部增加“批量下载（N张）”。N 为当前界面最新版本中已完成且具备工作区原图的数量；没有可下载图片时禁用，打包期间显示“打包中…”并禁用重复点击。部分完成也可下载，未完成／失败图片不加入；下载失败保留所有结果并可重试。

一次下载一个 ZIP，按“主图／详情页”建立目录，组内按图片位置排序并以两位序号命名，保留原图扩展名。例如 `主图/01-商品首图.png`、`详情页/01-首屏.png`。仅单类任务时包含对应目录。重试后的图片使用当前所显示的最新版本，不回退旧版本或使用缩略图。

复用 `downloadWorkspaceZip` 和 `/files/workspace/download_zip` 的认证、用户／组织文件隔离、流式 ZIP、大小限制和错误清单；兼容增加可选 `archive_paths`／`archive_name`，不移动／复制工作区原文件。ZIP 内路径、文件名和一一映射由后端校验，不允许绝对路径、越级、Windows 分隔符、控制字符或重名路径。文件已删除等部分错误沿用 `_errors.txt`。
