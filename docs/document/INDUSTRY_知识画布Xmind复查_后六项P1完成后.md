## P1：已有链路的剩余边界（以下为发现时记录，现已本地实现）

这些是代码确认的组合边界，不表示之前完成的主体功能没有实现。优先级按本项目常用操作的可达性判断，非 Xmind 官方缺陷等级。

| 编号 | 遗漏与影响 | 证据与验收 |
|---|---|---|
| R1 | 全局工具条、缩放条、反馈条尚未成为统一的安全区域；节点/标题工具条虽然测量了自身，仍可能与全局表面互相遮挡。节点自动定位和历史定位也未按实际遮挡区域计算。标题格式工具条没有传入创建端口障碍。 | toolsPosition 仍固定 top>=100，只接收节点/端口；revealNode 上边距64；fitView 固定128总垂直余量；全局工具条 top56 且可换行。逻辑探针：假定全局条占56..168，浮动条结果112..156，与其重叠；节点屏幕y80自动定位不移动。验收窄屏、多行全局条、上下加号、历史定位、125/150%缩放。 |
| R2 | 适配已覆盖曲线极值，但未覆盖关联线长文字；选中时也未包含双控制点及控制辅助线，可能看到曲线却找不到控制柄。 | fitAll 仅加入 curveBounds+8/zoom；CanvasRelations 的 text 独立在曲线中点上方渲染，控制柄在 control1/2。探针中曲线最上y=-1476，两个控制柄y=-1976，差500世界单位。应计实际文字包围盒，选中时计控制柄；普通状态不必被远端未显示控制柄拉小。 |
| R3 | 原位编辑标题变长、换行或字号变大后，没有持续保证光标及编辑区域仍在视野内。 | 编辑期间 revealNode effect 因 quick 直接退出；rename 只开始时按旧尺寸调用 revealQuick。内容可自适应增长，但无对应编辑区 ResizeObserver/光标跟随定位。此项是代码确认的可达性缺口，尚未浏览器实机复现。验收视口四边、48px字体、多行、中文IME、工具条改格式、减少动态效果。 |

## P2：功能与效率差异

| 编号 | 当前差异 | 对照依据/边界 |
|---|---|---|
| E1 | 左右自动平衡仍按顺序分边，缺按子树实际高度平衡、整图紧凑布局、同层等宽。 | [Map Style](https://xmind.com/user-guide/map-style-new)。小卡片不等于紧凑全图。 |
| E2 | 缺自由分支、浮动主题保持独立/自动挂接、允许重叠的显式设置。 | [Advanced Layout](https://xmind.com/user-guide/advanced-layout-new)。自由模式有意重叠不应自动当故障。 |
| E3 | 关联线缺未选节点先进入起线模式、外框作为连接对象；未手动固定锚点时不会随控制点自动择边。 | [Relationship](https://xmind.com/user-guide/relationship-new)。单选/双选、空白新浮动主题、端点重连、双控制点已支持。 |
| E4 | 关联线缺多线型、颜色、粗细、双端箭头及文字富文本；外框/概要括号缺独立线型颜色填充形状等。 | [Style](https://xmind.com/user-guide/style-new)。概要主题自身样式与括号样式应区分。 |
| E5 | 搜索缺上/下一命中、画布原文高亮、范围/整词/大小写设置、预览替换；标签/备注/任务筛选及集中看备注未齐。 | [Find and Replace](https://xmind.com/user-guide/find-and-replace-new)。现有标题/正文搜索、分页、列表定位不是缺失。官方页面Mac搜索键有异常写法，不能照抄，具体键位安装版核验。 |
| E6 | 图片缺独立选中、Delete只删图片、右键恢复原大小、直接拖到标题上/下方。 | [Local Image](https://xmind.com/user-guide/pic-new)。上传、拖文件到节点、剪贴板截图、缩放及弹窗上下位置已有。 |
| E7 | 局部下划线/删除线未齐；备注仍纯文本；快捷强调样式和可复用自定义主题未齐；结构分支线样式未齐。 | [Style](https://xmind.com/user-guide/style-new)。整节点支持的下划线/删除线不等于TitleRun支持。 |
| E8 | 当前右/左/左右/上/下5种排列，不覆盖时间轴、鱼骨、矩阵、树表等结构。 | [Structure](https://xmind.com/user-guide/structure-new)。已有混合子树方向不是所有结构缺失。 |
| E9 | 缺Shift+方向扩选、目录连续范围选择、按层级选择/展开、折叠数量提示。 | [Fold](https://xmind.com/user-guide/fold-unfold-subtopic-new)。递归全部展开/折叠和修饰键点选已支持；具体范围选择键位待安装版核验。 |
| E10 | 空间独立的缩放、平移、选择与折叠状态记忆未完善，刷新或切空间后的阅读连续性不足。 | 当前视野/previous/folded在页面内存；持久草稿不代表持久浏览状态。属于本产品效率建议，非已证实Xmind所有版本策略。 |
| E11 | 对外复制纯文本缺缩进层级；缺Xmind/Markdown/OPML导图结构导入、PNG/SVG/PDF/Markdown等导出与打印。 | [Import](https://xmind.com/user-guide/import-new)、[Export](https://xmind.com/user-guide/export-new)。多行缩进文本创建和知识附件上传已有，不能混淆。 |
| E12 | 缺自定义快捷键、命令检索、按操作系统显示精简键位、工具条/加号显示偏好、默认缩放/CJK字体偏好；没有应用内减少动态效果覆盖设置。 | [Settings](https://xmind.com/user-guide/preferences-new)。系统prefers-reduced-motion监听和相应即时反馈已实现。 |
| E13 | 缺可编辑大纲模式，目录还不是双向编辑、缩进/反缩进、重排的Outliner。 | [Outliner](https://xmind.com/user-guide/outliner-new)。官方提示桌面大纲当前仅本地文件可用；本产品云端需自行设计权限与版本，而非直接套用。 |
| E14 | 缺主题到主题链接/回链、跨空间授权跳转。 | [Link](https://xmind.com/user-guide/link-new)。年度总结/项目计划已被澄清为模板，不能再次混成内部链接。 |

## 跨平台与动态效果：验收项，不冒充已确认Bug

- Mac：Cmd/Option/Fn、中文IME、触控板捏合/惯性、连续打字与格式工具焦点。
- Windows：Chrome/Edge、Ctrl/Alt/Shift、Delete/Backspace、中文IME、高DPI及125%/150%缩放、鼠标和精密触控板。
- 不占用浏览器Cmd/Ctrl+R、Cmd/Ctrl+Shift+R等硬刷新键；菜单提供等效能力。编辑框中的撤销与画布撤销保持边界。
- 减少动态效果开启/运行中切换时，选中、落点、保存、撤销结果仍清晰；不依赖动画结束解锁，边缘平移继续工作。没有证据显示现有系统支持失效，也没有安装版Xmind证据要求照搬某种动效时长。
- 100/1000/5000节点容量分档、慢网/应答丢失、多标签/多人修改/权限撤回需组合验证。未测性能不得宣称卡顿，也不得宣称达标。
