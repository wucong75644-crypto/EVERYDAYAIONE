# 知识画布主题编辑 P1

## 本次行为

1. 标题改用多行原位编辑。Shift+Enter 插入换行，Enter 完成；中文组合输入时不提交。现有 200 字限制继续生效。标题保留显式换行并自动换行，保存时将尺寸与受影响布局一起提交。
2. 单选可编辑节点显示宽度手柄。拖动实时预览，按缩放比例换算，松手保存一次，Esc/取消捕获恢复。范围 160–800 像素。左右键微调 10 像素；Home、双击手柄、插入菜单恢复默认 272 像素。样式面板也能输入宽度。宽度属于节点布局资料，不属于格式刷样式。
3. 新增“只删除当前主题（保留子主题）”。Mac ⌘Backspace、Windows Ctrl+Delete，或右键菜单。只删除单选目标，直接子主题提升到原父级并占据原排序位置，后代关系、正文和文件身份保留。根主题删除后子主题成为独立主题。普通 Delete/Backspace 仍删除整支。概要成员引用替换为提升后的子主题，失效范围清理，外框尽量转由剩余成员承载。
4. 单选主题后 Alt+↑/↓（Mac Option+↑/↓）调整同级顺序，复用整支拖动的布局与版本校验。同级前后顺序不随视觉方向反转；最终排布跟随右、左、左右、向上、向下结构。首尾越界无操作，不创建历史记录。
5. 已修改标题通过 F2/空格/菜单编辑时光标位于末尾；默认标题全选。直接打字继续替换。双击实际标题文字时优先采用浏览器文字命中位置，不支持该 API 的浏览器回退末尾。输入框仍支持原生选区、文字撤销与粘贴。

## 实现

- `topicEditing.ts`：尺寸估算、编辑选区、文字命中、键盘排序、单主题删除布局规划。
- `TopicWidthHandle.tsx`：缩放感知预览、指针捕获、取消和键盘控制。
- 页面沿用现有 `act`、未知收据核对、历史定位和动态机制。减少动态效果时沿用现有即时落位；宽度预览跟手，不叠加补间。保存期间浏览发生变化时不抢回焦点和选中状态。
- `CanvasData.width` 是可选布局字段；默认宽度不写值。复制、历史和草稿沿用完整 canvas_data。样式面板仅在用户修改宽度时向所选节点应用，避免无意重置其他节点宽度。
- 新迁移 `322_knowledge_topic_editing.sql`，没有改动已应用迁移。新增 `delete_topic` 命令，在容器锁和权限/版本检查下原子执行布局、子主题换父、排序、范围处理、事件、收据和历史记录。删除目标用既有历史隐藏语义保留恢复能力；子主题新版本保留原正文。不执行生产迁移。
