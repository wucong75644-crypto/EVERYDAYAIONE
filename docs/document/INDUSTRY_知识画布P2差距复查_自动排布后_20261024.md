## 自动排布后还应验证的组合边界（不冒充已复现缺陷）

- childDirection新分支默认方向仍按数量奇偶选择；最终auto_balance按实测高度。需验证按钮方向、预览、键盘新增与最终落位是否连贯，手工拉线保留松手位置的约定仍有效。
- 同层等宽后多行、局部大字号、图片宽度、跨层移动、概要子主题、浮动工具条和端口避让的尺寸取值应组合检查，不能仅凭独立开关测试断言全部一致。
- 自动平衡当前为确定性贪心，非全局最优求解；官方说明只承诺平衡高度，不公开算法，不能认定必须完全复制坐标。
- 大图100/1000/5000节点重排耗时、连续撤销响应和减少动态效果下最终反馈需专项测量；未测不能声称卡顿或达标。

## Mac / Windows / 减少动态效果

- Mac：Cmd/Option/Fn、中文IME、触控板惯性/捏合、编辑框与画布撤销边界。
- Windows：Chrome/Edge、Ctrl/Alt/Shift、Delete/Backspace、中文IME、精密触控板及125/150%缩放。
- Ctrl/Cmd+F的搜索接管范围、编辑输入框原生快捷键及浏览器保留键应明确；不照抄Xmind桌面Ctrl/Cmd+Shift+R关联线快捷键。
- 新选择/筛选/大纲/视图恢复均保留可见焦点、结果高亮和状态说明；减少动态效果开启及运行中切换时不飞入、不过渡依赖解锁，仍呈现落点/完成状态。
- 当前系统减少动态效果已实现；应用内“跟随系统/减少动态”的覆盖设置是可选增强，不是已发现的失效。
