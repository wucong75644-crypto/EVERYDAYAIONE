# 画布目录定位坐标一致性

2026-10-29，本地修复，尚未提交部署。

根因：结构化导图的实际节点位置由 `mindmapView` 根据折叠和内容尺寸生成，与数据库中的原始布局位置可以相差很大。目录 `locate` 已使用排版后的位置，但选中后的自动可见性效果再次使用 `scene.nodes` 原始位置，覆盖正确的视野。用户看到目录仍选中、画布变空，节点本身没有通过浏览动作被删除。

复现：合成结构化导图保留远处原始坐标、自动排版到正常可见位置；点击目录后，修复前动画与减少动画两个用例都把目标移到屏幕外（测试中屏幕横坐标约 -9180px）。

修复：相机的自动可见性与历史操作后的聚焦都采用当前排版节点快照，与实际卡片位置一致；位置变化和正文/附件尺寸变化触发重新核对，避免迟到加载导致选中目标漂出可视区。保留原始坐标、层级、编辑保护、手动视野、折叠与浏览偏好；无后端写入、无数据迁移。

定向覆盖：普通/减少动画、目录点击、键盘导航、折叠目标自动展开、相邻长正文尺寸变化引起重排，以及只浏览、不发出知识修改命令。实际浏览器使用正式画布组件和合成布局数据核对目标矩形在视口内；不冒充生产数据现场复验。随后运行画布及相关定位、布局、动画回归、类型/静态检查和构建。

回滚本次前端修改即可；不需要重新导入文件或恢复已删除内容。实际生产版本以受控发布记录为准。

验证结果：6 个测试文件、378 项测试通过（其中画布页面 349 项）；ESLint、TypeScript 检查通过；生产构建及 PDF worker 检查通过。浏览器中目录目标完整落在画布视口内并保持选中，矩形证据与截图保存在本机私有验收目录。构建存在既有分块体积提示，测试存在 act 提示，无失败。临时浏览器页面、合成入口和本地服务已清理。
