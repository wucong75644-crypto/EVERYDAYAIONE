结构检查逐文件复核摘要/尺寸及引用，和已有两阶段模型语义检查分开，检查固定内容版本与素材摘要。语义检查只检查文字及卡片结构，无法据此证明图片版权或图像视觉语义。必须保存当前包检查后才创建意图。

发布意图唯一绑定组织、内容版本、账号和可见范围。确认端点由 OrgCtx 提供操作者，校验最终摘要、原凭据版本、素材与当前版本后一次性消费；只经 ToolExecutor/Policy/Dispatcher 的现有确认回调执行 agent_reach:create_post。发送附近中断、超时或未知状态进入 uncertain，GET 将滞留 dispatching 保守显示 uncertain，不自动重发。已提交/不确定的同版本意图不可重复创建。可记录人工核验：可信平台 ID + 完整链接 + 核验说明与操作者时间，明确 manual，不冒充自动核验。
