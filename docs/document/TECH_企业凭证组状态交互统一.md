# 企业凭证组状态交互统一

## 目标

统一企业管理中 ERP 凭证组与企业微信机器人凭证组的展示和编辑方式，避免把已配置状态伪装成输入框，并隐藏仅供并发控制使用的内部版本号。

## 实现范围

- 新增轻量的凭证组展示组件，统一“已配置 / 未配置”和“重新配置”入口。
- ERP 的应用凭证、Token 凭证继续独立保存，保留现有完整性校验与版本校验。
- 企业微信机器人 Bot ID 与 Secret 继续作为一个不可拆分的凭证组保存。
- 两类连接测试改为次级操作，但不改变测试 API、成功或失败反馈。
- Corp ID、自建应用凭证、后端接口、数据库和运行时配置不在本次范围。

## 状态与失败行为

- 未配置：直接展示组内输入字段。
- 已配置：折叠敏感字段，仅展示明确状态和“重新配置”。
- 重新配置：展示全部必填字段、保存和取消；取消不修改服务端状态。
- 字段缺失、保存失败、连接失败：沿用现有页面级错误反馈。
- 保存中或测试中：禁用对应操作，避免重复提交。

## 验证与回滚

- 组件测试覆盖 ERP 与企业微信的已配置、展开编辑和内部版本隐藏行为。
- 运行定向 Vitest、TypeScript/Vite 构建、调用方搜索与结构阈值检查。
- 改动只涉及前端展示，可通过回退对应前端文件恢复，不需要数据迁移。
