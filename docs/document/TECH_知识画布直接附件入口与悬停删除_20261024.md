# 知识画布直接附件入口与悬停删除

## 行为

- 节点的文件资料直接弹出上传文件、从工作区选择、引用其他节点文件菜单；查看全部附件保留完整管理入口。上传在原生文件选择后启动，工作区与引用使用紧凑选择面板。
- 图片右上角、附件文件名末尾的移除按钮平时隐藏，鼠标悬停或键盘聚焦时显示；触摸设备保持可见。只读节点不提供移除入口。
- 图片上的移除仅取消画布图片展示；附件移除取消当前节点绑定，保留源文件与其他节点引用。绑定移除前确认，既有固定版本和权限检查不变。
- 正文框支持四边及四角调整大小，拖动结束继续输入，Esc 取消调整；尺寸仅保留本次打开期间。正文自动保存与草稿保护沿用现有机制。

## 实现与数据

复用 TopicWidthHandle 的 Pointer Events、键盘调整和边界约束，节点默认行为不变。附件入口按请求代次和身份检查响应，避免较晚的旧抽屉请求覆盖新操作；取消与完成均释放忙状态并返回画布焦点。

新迁移 330 在现有 file_remove 命令的事务内清理与被移除 binding_id 匹配的图片或视频展示，并增加节点修订。保留现有权限、版本、幂等回执与容器修订检查；不修改已应用迁移。附件删除造成容器修订变化，旧画布历史不能恢复失效绑定。
