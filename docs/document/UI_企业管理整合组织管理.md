# UI 设计：企业管理整合组织管理

> 版本：V1.0 | 状态：已确认 | 日期：2026-07-27  
> 依据：[REQ_企业管理整合组织管理.md](./REQ_企业管理整合组织管理.md)

## 信息架构

```text
管理后台
└─ 企业管理
   ├─ 组织管理
   │  ├─ 成员与任职
   │  └─ 群聊管理
   ├─ 企业信息
   ├─ 企业微信
   ├─ ERP 凭证
   └─ AI 配置
```

## 成员与任职

统一列表展示头像、企业内显示名、企业角色、部门、职位、数据范围和企微关联状态。
顶部提供总数、企微状态筛选和邀请成员入口。成员编辑态集中处理企业内显示名、角色和
任职信息；保存失败保留输入并允许重试。

正式成员加载失败时显示错误；企微状态单独失败时保留成员列表并显示“状态暂不可用”；
筛选无结果与企业无成员必须使用不同空状态。

## 群聊与企业微信

群聊管理展示机器人收集到的群聊、chatid、活跃时间、消息数和手工群名。企业微信板块
只管理凭证、状态和连接测试，不重复群聊业务数据。

## 入口与权限

- 聊天侧边栏继续提供“管理后台”，聊天顶部移除独立组织管理图标。
- 旧组织管理地址跳转到企业管理的组织管理板块。
- 仅当前企业 `owner/admin` 可见；后端继续作为最终安全边界。

## 交互验收

1. 深度链接可以直接定位企业管理的组织管理板块。
2. 同一成员的角色、任职和企微状态可在一个列表理解和管理。
3. 企微筛选不切换到第二套员工页面。
4. 群聊管理和企业微信凭证配置职责清楚。
5. 加载、空、失败、保存中和保存失败均有可见反馈。
