# 知识画布 P1 完整使用场景验收

日期：2026-10-24。基准：当前独立任务工作树，未部署。只使用合成资料、本地浏览器和独立 loopback 测试数据库，没有生产写入、真实业务资料修改或员工账号登录。

## 本轮目标与边界

按连续操作、复杂内容组合、草稿恢复和慢网保存验证现有 P1，不扩展 P2。Mac/Windows快捷键语义和减少动态效果由相关自动化覆盖，原生Windows和生产环境仍待人工验收。

## 已复现并修复的阻断

### 1. 未知保存结果核对时重建创建编辑器

触发：创建主题提交→应答丢失→继续输入→刷新核对。

正常保存返回时已有 standalone 标记保留编辑器，但 reconcileSaved 未走相同呈现规则；从新建草稿变为已创建节点时切换到内联编辑，DOM重建，光标重置。补齐核对路径的呈现标记，仍先重放原操作编号和原负载，再用已创建节点的新版本保存后续文字。测试锁定同一编辑元素、输入和选择位置。

### 2. 旧企业/旧会话的慢请求锁住新会话

触发：原企业发起未完成保存→切企业→新企业不能编辑。仅检查账号企业字符串也不能区分“离开后再回到同企业”的两次会话，旧请求的finally还可能解除新请求的保存锁。

使用单调会话代数隔离请求：身份生命周期重置本会话保存/快捷创建锁；旧返回不能更新场景、错误、pending或quickSaving。保留原企业持久草稿和原请求回执，不撤回已经发送的服务器操作。补测试覆盖跨企业未完成请求，以及离开再返回同企业后旧应答到达、新保存仍保持锁定。

### 3. 概要在目录中重复出现

复杂场景浏览器发现概要既出现在逻辑父级下，也被当作物理parent_id=null的根节点再次显示；折叠原分支后残留一条入口。目录的子级遍历已用逻辑父级，根节点过滤和层级符号尚用物理父级。统一使用summaryParent，不修改存储父子关系。自动化与浏览器复核覆盖目录唯一入口和折叠隐藏。

### 4. 未知保存提示覆盖原位短标题

真实关闭标签页恢复场景中，全局错误提示之外，内联标题中的重复绝对定位提示会盖住短标题，影响核对内容。内联编辑保留全局错误与刷新核对入口，不重复覆盖标题；新建独立编辑卡仍保留卡内提示。补测试锁定标题草稿内容和唯一全局错误提示。
