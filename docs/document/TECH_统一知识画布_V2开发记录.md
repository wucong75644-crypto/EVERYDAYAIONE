## 用户可用行为

节点“文件资料”打开附件面板，按节点当前读写权限展示操作：

- 上传新附件，或向已有附件上传新版；旧版本可独立选择、预览、下载。
- 从本人当前企业/个人 Workspace 的相对路径建立固定快照。源文件随后改名、移动、覆盖或删除均不改变快照。
- 选择可读来源节点、附件和明确版本，在目标可写节点建立引用。来源继续更新不会推进目标版本；移除来源绑定后，目标引用仍可读取。
- 移除附件只移除该绑定，所有旧版本经此绑定也立即不可读；不删除源文件、内容字节或其他绑定。
- 右侧搜索当前空间的节点标题、当前正文、附件标题/文件名和已提取的当前附件正文。结果定位回画布并展开祖先分支；不搜索对话、其他不可读空间或附件旧版本。
- 正文编辑保留 V1 乐观版本检查；历史版本只读查看，不覆盖未保存草稿。文件更新也携带预期版本号，并发修改只允许一个成功，另一个明确冲突。

### 格式和边界

单文件 1 字节至 20MB，每节点最多 100 个有效绑定。文本须 UTF-8；文件名最多 180 字符；类型、内容签名、大小和压缩内容均校验。Office/ZIP 压缩包最多 2000 项、解压总量不超过 50MB，拒绝加密 ZIP。

| 类型 | 预览与搜索 |
| --- | --- |
| TXT、MD、JSON、CSV、TSV、YAML、XML、日志及支持的代码文本 | 只读文本/表格预览；正文最多索引 20 万字符，超出明确标记“部分可搜索” |
| PDF | PDF.js 翻页/缩放；最多提取前 200 页、20 万字符；扫描件无 OCR，不冒充已可搜索 |
| DOCX | 复用 mammoth + DOMPurify 的基础 Word 预览；提取段落和表格，不承诺高级版式保真 |
| XLSX | 复用表格适配器；索引最多每表 1 万行、200 列及总计 20 万字符；不执行公式或外部链接 |
| PNG/JPEG/GIF/WebP、MP4 | 图片查看/视频播放；无 OCR 或转写，不索引媒体正文 |
| DOC、XLS、PPT、PPTX、ZIP | 本版只下载，预览按钮禁用并说明原因 |

每个文件版本显示“正文可搜索 / 部分可搜索 / 提取失败 / 无可搜索正文”。提取失败不将原件伪报为已解析；仍可下载，适用格式可尝试客户端预览。提取子进程有 CPU、执行时间和 Linux 内存上限，无新依赖或外部服务。预览不是 Office 编辑。

## 实现与数据边界

### 数据与存储

- 303 增量迁移增加 `kb_file_bindings`、`kb_file_versions`、`kb_file_binding_versions`，配置强制 RLS 和受控函数。运行角色不能直接写这些表，也不能直接查询全局文件版本表。
- `user_assets` 是唯一 canonical 资产登记。私有内容版本在同一事务内调用既有 `register_user_asset`，写入资产、来源、不可变版本、绑定映射和幂等回执；任何后续约束失败都会全部回滚。
- canonical workspace 提供者使用内部保留键 `knowledge-private/{内容版本 UUID}`，元数据 `storage_class=knowledge_private` 由私有服务解析，不冒充 CDN 对象或用户相对路径。登记 URL 是首个绑定的受控 API，不返回公共链接。
- 字节位于 NAS 根的 `.knowledge-versions/{企业或personal}/{上传者}/{内容版本}/content`，在所有用户/频道 Workspace 和沙箱挂载范围之外，不调用 OSS 同步。UUID 路径、符号链接拒绝、私有目录、不可覆盖发布和 SHA-256/长度复核保证固定内容读取。
- 304 保持原资产查询函数的签名、所有者和授权，过滤私有知识资产，防止通用管理员资产列表/数量/下载解析泄露知识附件元数据。普通资产行为保持原样。

### 接口

| 接口（前缀 `/api/knowledge`） | 行为 |
| --- | --- |
| `POST /objects/{id}/files` | multipart 文件 + command_id；更新附带 binding_id 和 expected_revision |
| `POST /objects/{id}/files/from-workspace` | 仅快照当前账号自己的 Workspace 文件 |
| `POST /objects/{id}/files/reference` | 校验来源可读、目标可写后固定 source_revision |
| `GET /objects/{id}/files` | 当前有效附件列表，不返回上传者定位信息或源路径 |
| `GET /objects/{id}/files/{binding}/versions?before=...` | 每页 50 条，版本倒序 |
| `GET /objects/{id}/files/{binding}/versions/{revision}/content` | 经当前绑定鉴权后返回原件；磁盘读取后再次检查权限 |
| `DELETE /objects/{id}/files/{binding}` | 乐观版本校验、幂等移除，不物理删除 |
| `GET /objects/{id}/versions`、`.../versions/{revision}` | 正文历史元数据分页与按需正文读取 |
| `GET /containers/{id}/search?q=...&cursor=...` | 1–200 字符字面子串搜索，支持中文、大小写不敏感；50 条一页，UUID 游标 |

所有读取依赖当前账号/企业和当前权限，绑定/节点移除或撤权均拒绝历史读取；无权和不存在使用同类通用 404。文件路由禁止缓存；原件响应强制下载、nosniff 和 sandbox CSP。知识画布总开关覆盖所有文件路由，上传还要求工作区文件服务已启用。

前端经现有认证请求取得版本 Blob，复用 PreviewHost/registry。关闭、切换或卸载时撤销 Blob URL/取消旧请求；不把上传者 Workspace 路径交给其他成员，也不向 URL 填 Token。

### 重试、保留与回滚

上传使用账号、企业和 command_id 派生稳定内容版本 ID。重复提交复用同一回执，不重复登记或添加；变更载荷拒绝。正文提取结果不参与重试身份，避免一次解析超时导致同一原件无法核对。

网络或服务失败保留原文件与同一操作标识，提供“重试同一操作”；未确认前禁止其他文件修改和切换附件面板。明确冲突保留提示并重新读取当前列表，不静默覆盖。初始列表迟到不会覆盖上传后的列表，旧企业/节点请求不会写入新界面。

移除绑定不清理字节；canonical 资产有任何知识内容版本时，删除、软删除及身份/摘要变更均被数据库拒绝，包括历史和已移除绑定。未开放物理清理，保留周期和清理须后续明确；遇到不确定提交的孤立文件保留供核对，不猜测删除。

开发阶段未执行生产迁移。本次发布须按权限/迁移改动进行受控完整检查，由发布入口核对和执行生产迁移。应用回滚可关闭知识画布或回退代码，保留新增表及字节，不自动删除用户内容。

## 2026-10-23 生产 PDF 预览修复

生产用户验收发现 PDF 上传、正文提取成功，但预览报 worker 动态导入失败。该静态资源 HTTP 200，Content-Type 为 application/octet-stream；生产 Nginx 的 MIME 映射未识别 .mjs，浏览器模块加载因而拒绝。开发服务器能够识别 .mjs，原组件测试和本地预览不能覆盖此生产差异。

在构建产物边界将显式 PDF worker URL 资产输出为带内容哈希的 .js，使用服务器已有 JavaScript MIME 映射；worker 原始内容、react-pdf 依赖版本解析及其他资产命名均不变。新 URL 也避免复用旧 .mjs 响应的一年缓存。不修改权限、文件数据或数据库；回退应用代码即可回退本次改动。

构建后自动检查所有 PDF worker 扩展名、显式资产与 react-pdf 依赖原件字节一致、应用 bundle 引用正确输出；保留对 PDF.js bundled fallback chunk 的兼容。复现旧 .mjs 产物时检查拒绝，修复产物通过。预览定向测试 68 项通过，TypeScript/Vite 构建和定向 ESLint 通过。最终部署和生产页面复验结果以本次发布日志及验收截图为准。
