## 行为

1. 标题只有局部格式或对齐变化，也视为未保存草稿。备注、标签、任务、样式、图片、视频、网址、外框编辑以及关联线文字保存实际输入，刷新或关闭后重新打开可恢复。多选样式保存原目标集合；图片和视频保留固定文件版本。上传结果未知时保留核对入口，不把文件重复上传。
2. 草稿继续按账号、企业隔离。恢复重新获取场景、检查目标存在及写权限；版本变化提示冲突，保存仍携带原版本，不能静默覆盖新版。被删除的外框或关联线不能恢复到别的目标。
3. 概要的存储父子关系不变。通过覆盖成员计算逻辑归属：覆盖范围完整移动、复制、删除、折叠时带上概要及其后代；只移动部分成员时保留原父主题下的剩余范围。删除普通主题保留子主题时，范围替换为提升后的子主题。覆盖范围为空时隐藏概要及其后代；撤销恢复。单独删除概要不删除被汇总主题。
4. 新外框数组及旧外框都参与左右分组。跨越、交叠的范围按完整区间合并分边，范围语义不改动；编辑已有外框保留它在数组中的位置，避免层叠次序改变。
5. 本轮沿用画布历史和动态系统，不增加平台独有快捷键或强制动画。概要导航、定位和撤销后展开采用逻辑父级；减少动态效果仍采用原有即时反馈路径。

## 实现与数据

- 前端 summaryScope 统一逻辑父级、完整范围及可见性；summaryLayout 计算概要随范围的位移。布局、导航、复制和历史定位共享该规则。
- 弹窗通过受控草稿回传实际表单值；恢复保留原节点和容器版本。草稿不保存本地 File 或文件字节。
- 新迁移 `backend/migrations/327_knowledge_summary_scope.sql`：私有范围函数用于移动、删除和快照检查；成员协调在同一历史命令内完成。删除允许携带剩余概要的位置更新，保持原子性。未改写已存在迁移。
- BatchPayload 省略未提供的 nodes，维持旧请求的幂等规范化格式。
