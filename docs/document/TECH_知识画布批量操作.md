# 知识画布：多选、复制粘贴与删除

2026-10-23，接续画布交互任务，用户授权实施，不部署。

## 行为

- Shift、Cmd 或 Ctrl 点击增减选择；空白拖动框选当前空间内可见卡片，Shift 框选追加。Cmd/Ctrl+A 选择当前导航空间的可见节点，Esc 清空选择或取消本次框选。普通点击恢复单选。折叠后代无需展开，会随分支操作；界面显示显式选择和包含后代的数量。
- Cmd/Ctrl+C 与工具栏/右键复制共用分支剪贴板结构；系统剪贴板保存私有 MIME 的对象引用与版本，不写正文或文件字节，普通文本格式为标题。按钮通过同步 copy 事件写系统剪贴板，不依赖事件目标位于 React 根内。浏览器拒绝时明确提示并保留内部“粘贴分支”按钮。
- Cmd/Ctrl+V 或按钮/右键粘贴。同一用户、组织、原知识空间内操作；选中节点时贴为其子级，无选中则为根分支。全部复制节点保留相对位置，安排在当前内容下方避免与已有内容重叠，并定位新分支。父子重叠选择只复制一次，保留种类、标题、正文、内部关联及当前固定文件版本；新节点/布局/文件绑定 ID，原文件 version_id 不变，不复制指向分支外部的关联。
- 复制记录要求原空间版本未变化，防止默默复制已更新正文、文件或树形。重复粘贴只接续本页面自身成功粘贴后的容器版本；其他修改后需重新复制。单次复制最多 1000 个节点。
- Delete / Backspace（Mac ⌫）、工具栏及右键删除整支。服务端扩展所有后代，整批隐藏；不物理删除旧对象、正文版本、固定文件或快照。删除与粘贴各为一条持久历史，接入上一批撤销重做。输入、正文、对话框保留系统文字编辑行为，IME 与保存中不触发画布命令。
- 跨空间粘贴未开放，避免资料权限意外扩散；本批起初沿用单分支拖动，后续多选共拖及剪切行为见本文第六批记录。不是 Xmind 原生文件格式导入导出或跨应用主题格式互通。

## 实现与事务

- contracts 增加 copy_branches / delete_branches 严格载荷：container_id、expected_container_revision、objects（ID+版本），复制附目标父级和统一坐标偏移。
- 308 为尚未发布的任务迁移，本批仅增加批量命令路由及历史跟踪；309 新增 owner-only kb_apply_batch_command。305/306 无改动。
- 现有 kb_canvas_command 持 actor/org 历史锁和容器锁，复核身份、权限、幂等、容器/对象版本，捕获前后差量。309 复核来源同空间与可见性，递归扩展并去重，复制要求提交完整来源集合，限制总量；先父后子复制、同级有序追加。新文件绑定引用原不可变文件版本。单事务写对象、正文版本、布局、文件绑定、内部关系、容器版本、审计与回执；失败整体回滚。
- 删除沿用 undo_hidden，当前画布、检索及新引用不可发现，历史固定来源按当前 ACL 仍可读取；恢复不回拨版本号或权限。权限丢失、并发更新和过期历史按既有机制拒绝。
- 回滚：本批代码与309迁移作为同一候选发布；未执行生产迁移。撤回 UI 可以保留新增函数和软隐藏数据；不可删除已产生历史对应的版本或文件。
