# 拉线创建：固定落点与圆点端点（2026-10-24）

## 已确认行为

从哪个圆点拉出，线头固定连接那个圆点；在哪里松手，新节点保留在哪里。输入标题、确认、补存、刷新和自动排布不能覆盖手动结果。圆点和子级加号创建子主题，底部同级加号创建同级主题，父子语义不变。主动拖动、重排及粘贴仍使用用户的新目标位置。

## 根因与修复

此前 create_object 使用松手坐标，但后续标题补存触发整树排列；普通标题/内容排布也没有持久化的手动落点意图。结构线另按相对位置推断端点，导致节点位于父节点上方时，线头从右圆点换到顶部。

fixedPosition 编辑会话补存使用空 nodes 和当前容器版本，不再附加整树排列。新增 canvas_data.manual_layout：存在即保留手动位置，子主题记录成对的源/目标边缘归一化端点，同级创建记录空对象保留落点。预览与正式结构线使用实际起点；有手动子主题时圆点方向保留。自动结构/内容排布恢复手动节点及其分支位置；复制、剪切粘贴和主动调整层级的规划临时忽略旧位置标记，实际数据保留。

新增前向迁移 328，未改已应用迁移：严格校验端点成对、边缘位置及数值范围；创建时在同一事务写入元数据，并纳入原有撤销重做快照、权限及容器版本校验。旧节点无元数据时行为不变，不回填历史坐标。Repository 对未提供字段省略序列化，保持旧命令回执兼容。
