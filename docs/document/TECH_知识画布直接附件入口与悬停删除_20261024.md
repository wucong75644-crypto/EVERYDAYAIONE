# 知识画布直接附件入口与悬停删除

## 行为

- 节点的文件资料直接弹出上传文件、从工作区选择、引用其他节点文件菜单；查看全部附件保留完整管理入口。上传在原生文件选择后启动，工作区与引用使用紧凑选择面板。
- 图片右上角、附件文件名末尾的移除按钮平时隐藏，鼠标悬停或键盘聚焦时显示；触摸设备保持可见。只读节点不提供移除入口。
- 图片上的移除仅取消画布图片展示；附件移除取消当前节点绑定，保留源文件与其他节点引用。绑定移除前确认，既有固定版本和权限检查不变。
- 正文框支持四边及四角调整大小，拖动结束继续输入，Esc 取消调整；尺寸仅保留本次打开期间。正文自动保存与草稿保护沿用现有机制。

## 实现与数据

复用 TopicWidthHandle 的 Pointer Events、键盘调整和边界约束，节点默认行为不变。附件入口按请求代次和身份检查响应，避免较晚的旧抽屉请求覆盖新操作；取消与完成均释放忙状态并返回画布焦点。

新迁移 330 在现有 file_remove 命令的事务内清理与被移除 binding_id 匹配的图片或视频展示，并增加节点修订。保留现有权限、版本、幂等回执与容器修订检查；不修改已应用迁移。附件删除造成容器修订变化，旧画布历史不能恢复失效绑定。

## 备注入口精简（部署后新增，未部署）

按用户确认，画布全局工具条和节点浮动工具条移除备注按钮，标签按钮保持原位。节点右键菜单提供备注入口，直接使用右键目标节点；沿用原备注弹窗、保存、撤销重做、草稿恢复与只读权限控制，不迁移或删除已有备注。已有备注的节点内提示仍可打开查看，F4 入口保留。

验证覆盖工具条入口、已有备注读取及编辑保存、标签元数据保留，以及原弹窗草稿恢复回归。仅前端入口变化，无数据库改动。

## 右键菜单精简（未部署）

节点菜单第一层保留修改排列类型、创建、备注、剪切、复制、粘贴、分支、删除、更多。创建文档/规则/父主题进入创建子菜单；折叠/展开全部后代进入分支子菜单；两种删除方式进入删除子菜单；历史版本与有权限的项目成员管理进入更多。空白菜单保留按排列类型创建主题和在落点创建内容的语义。

移除重复的展开查看、修改标题、回到中心主题入口，继续通过节点编辑按钮、双击标题、全局中心按钮和原快捷键使用。点击空白或 Esc 关闭，去掉关闭菜单条目。只调整入口，不改变数据、操作命令或历史记录。右键菜单快捷键按当前设备 Mac 或 Windows 分别显示；子菜单复用原碰撞避让、键盘和减少动态效果机制。

## 附件菜单尺寸与旧画布快捷创建（未部署）

附件直接菜单限定 13px 字号、紧凑行高和内边距，避免继承其他界面的过大字号。

无显式排列设置的旧节点，原先使用固定 x+330/y+194 作为快捷创建起点，图片或手动加宽后的源节点可能与起点相交，再由自由位置避让向下移动。改为按实际节点宽高定位：首个子级沿分支方向伸出并中心对齐；已有子级时跟随末尾子级所在行/列，避开其完整子树；同级继续在当前主题之后插入。显式排列仍由既有布局器处理，拉线指定位置的创建不变。回归覆盖大图片节点 Tab 的预览与确认位置、左右上下方向、子树间距和既有连续创建链路。
