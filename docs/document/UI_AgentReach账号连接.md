# Agent Reach账号连接交互

2026-10-11。实现范围：组织专用账号，管理员连接、成员按授权使用；个人账号页面不在本期。

入口沿用设置→组织管理→互联网账号。页面先展示已连接账号、最近验证状态以及我的操作回执；管理员可检查、重新连接、断开，并维护成员查询/写入权限。

连接新账号：选择平台→查看真实连接方式与前置条件→进入连接流程→扫码、官方授权或会话导入→服务端核实真实账号身份→显示账号名称→管理员分配成员权限。不要求填写账号ID和凭据JSON。

- 小红书/B站：生成二维码，手机应用扫码，显示等待/手机确认/成功/过期。成功即隐藏二维码；过期可以重新生成。
- YouTube：准备授权后显示官方授权链接，在新页面选择组织频道并同意授权；回到原页轮询结果，成功显示连接状态。拒绝授权显示未完成，重新开始生成新会话。
- Twitter/X、Reddit：现有后端不提供网页登录授权。明确展示会话导入方式及操作指引，以密码框粘贴组织专用浏览器Cookie；验证后自动识别ID/名称，加密保存并清空输入。该流程仍偏技术操作，不能声称已有一键登录。若要求无手动Cookie，需要另行选定官方API后端或经用户控制的浏览器连接器，不能复用服务器个人浏览器。

未配置平台禁用连接并说明原因；网络检查失败与登录过期分别展示。成功状态指最近一次验证结果，不保证长期在线。重新连接必须匹配原账号，保留成员授权；换账号需要新连接与重新分配权限。取消扫码停止本地接入，不代表远端已结束登录；小红书扫描服务继续运行至上游四分钟超时，期间不将该服务交给其他会话。

前端保持已有组织设置样式，无新增设计系统或登录产品框架。键盘可操作表单，状态使用status，错误使用alert，二维码附明确替代文字，官方授权链接隔离opener。尚未进行真实账号扫码/授权验收。
