# 工作区、快麦与媒体改动归档说明

本文件记录原主工作树中曾经出现的工作区、快麦和媒体相关改动的整理结论。

## 已进入稳定主线

- 工作区浏览、上传、重命名、移动、删除和 ZIP 下载。
- 快麦数据源配置、凭证测试、手动同步和同步记录。
- 聊天附件、图片预览、图片失败恢复和发送失败处理。

这些内容已经随已验收任务进入 `origin/main`，无需从旧工作树重复提交。

## 不应从旧工作树恢复

旧工作树还保留了若干基于更早版本的 WebSocket、消息恢复、Token 刷新和发布脚本文件。
这些文件会覆盖稳定主线中较新的修复，因此整理时保留 `origin/main` 版本。

企业生命周期接口和 Web 消息幂等迁移属于独立风险批次，本次不纳入发布。
