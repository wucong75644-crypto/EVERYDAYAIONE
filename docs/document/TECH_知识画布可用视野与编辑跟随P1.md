# 知识画布：统一可用视野、完整关联线范围、编辑光标跟随

日期：2026-10-24。当前任务本地实现，尚未部署。仅前端，无数据库迁移或 API 契约变更。

## 行为与实现

### 统一遮挡区域

canvasOcclusion 按工作区本地屏幕坐标读取全局工具条、缩放条、空间位置条、反馈提示/关联线提示、分组操作条与底部提示。按真实位置计算保守的可用矩形；上方表面预留到其底边，下方表面预留到其顶边。可用矩形保持12px间距。浮动工具条继续检查真实节点、创建端口与表面矩形，同时使用可用区域上界作为屏内回退约束。

useCanvasOcclusion 在场景加载完成后建立 ResizeObserver 和子树变更监听，反馈出现/消失、工具条换行、工作区大小变化时合并微任务更新位置戳；卸载或身份变化清理观察器并丢弃旧回调。它不占用手势平移的动画帧循环。

方向键/选中节点自动定位、搜索定位、回到中心主题、撤销相关节点定位、创建/改名定位和适配全图共享该区域。原位文字工具条也避让方向化加号端口。界面表面不进入世界布局或撤销历史。

### 完整关联线适配

在既有曲线精确极值范围基础上，读取 SVG 文字 getBBox，保留相对文字基点的真实尺寸，并在候选缩放下重新定位其包围盒；选中且可写时额外加入两端控制柄范围，控制辅助线位于端点与控制柄连线范围内。未选中或只读时不为未显示的控制柄额外缩小视图。保留描边/箭头余量和并行线随候选缩放的迭代。

只计算当前空间可见节点对应的关联线，不自动展开隐藏分支。缩放和平移仍为浏览操作，不调用保存命令。

### 编辑光标跟随

useCanvasEditingVisibility 在实际输入、选择变化、字号/格式变化、编辑区尺寸变化和输入法合成结束后，按 Range 的 focusNode/focusOffset 获取光标矩形。编辑区放得下时保持整个编辑区可见；超过可用高度时优先保持光标可见，不自动缩小文字。合成期间暂停调整，在 compositionend 后处理。

只调整画布平移，不重建编辑器，不写标题、不恢复或改动浏览器选择、不抢夺格式控件焦点。编辑跟随使用即时必要平移；已有导航/适配继续沿用动态视口与系统减少动态效果路径。

- 工具条多行、提示条和底部提示的真实可用区域及安全适配。
- 场景加载后观察器建立、工具条高度变化、卸载清理。
- 长关联文字、选中/未选中控制柄范围；不写历史。
- 超高编辑区光标、保持当前选择/焦点、中文IME合成结束后跟随、已可见时不重复平移。
