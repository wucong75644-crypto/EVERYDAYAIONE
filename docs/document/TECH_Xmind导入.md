# Xmind 导入知识库

实现范围：离线上传 `.xmind`（现代 content.json / 旧版 content.xml），默认在当前企业新建仅导入者可管理的项目。成员共享沿现有项目成员权限操作。导入不访问任何外部链接。

## 数据映射

- 每个主题建立 topic，按原父子和兄弟顺序保存。无标题图片/链接主题保留为独立节点。多张 sheet 的根主题放在同一独立项目。
- 完整主题文字与备注写入初始正文固定版本；画布标题受现有 200 字限制，过长只缩短显示标题，正文不截断。主题正文因此进入现有搜索、分片、授权快照问答和自动整理，不只生成目录。
- 图片、内嵌附件和原件使用现有私有不可变文件存储及绑定版本。图片绑定 canvas image，可预览；正文/文件变更触发现有 derivation jobs，经原始分片、自动章节、标签向父层逐级汇总。人工正文及标签不被自动区覆盖。媒体采样限制及失败/partial 状态继续使用现有机制。原始 Xmind 是备份附件，未作为图片或外链内容解析；其 unsupported 状态可能令根目录覆盖标记为 partial，不能把这个标记误报为主题导入缺失。
- HTTP(S) 链接绑定现有 canvas link，同时正文注明“仅保留入口，未读取链接内容”；其他协议只以正文保留。不会抓取受限链接或猜测其中内容。
- 概要映射现有 summary members，保留概要主题与后代。折叠节点 ID 返回页面恢复折叠。自由主题保留在所属主题下并提示位置差异；外框、关联线、标记/任务与样式未对齐，提示查看保留的原件。

## 安全与事务

`xmind.py` 仅从 ZIP 内存读取，条目从不按原路径解压到磁盘。限制上传 20MB、展开 50MB、2000 条目、内容文件 8MB、1000 主题、64 层、单主题正文 20 万字、总正文 200 万字；拒绝重复路径、路径穿越、绝对路径、反斜线、加密、特殊文件、XML DTD/实体、缺失资源、无效概要及未知主题类别。文件发布复用 MIME 实测和大小限制；内嵌图片额外验证结构及 1600 万像素上限，并保存显示比例。

`POST /knowledge/imports/xmind` 复用 rollout、企业上下文、私有文件服务开关及运行时 scope；没有企业则提示选择企业。服务器校验完整输入后先发布私有不可变字节，再通过 `kb_import_xmind` 一次事务注册项目、节点、固定正文版本、附件、画布信息、事件、幂等回执和一条历史。任一注册失败回滚所有可见内容。磁盘已发布字节在失败或未知结果后保留用于同一命令重试，未注册字节没有对外读取入口；不在结果未知时删除可能已提交的文件。

导入以 actor+command 幂等，回执严格比较企业及原始 SHA/计划/文件元数据。前端在发送前把 identity+文件 SHA 的 command 存入 sessionStorage，同页失败或刷新后重新选择同一文件继续核对；存储失败则不发送。更换企业/账号卸载导入组件，旧响应不能更新新账号画布。已提交导入先以原始文件 SHA 和文件名核对授权回执，命中后不再解析原件或发布资源。重复回执仍重新核验权限，不会重复创建、重新解析原有媒体或复活已撤销项目。
