# 知识画布主题排列

2026-10-24，用户明确「主题类型」指排列结构，不是年度总结等预填内容。

## 操作和范围

- 双击空白直接创建当前默认主题，保留原位编辑和现有默认向右交互。
- 空白右键 → 创建主题 → 选择逻辑图（向右，默认）、逻辑图（向左）、思维导图（左右）、组织结构图（向下/向上），然后原位填写一个空主题；不生成示例业务内容。
- 已有主题右键 → 修改排列类型。仅修改布局与排列元数据，保留标题、正文、文件、父子关系、规则与权限。子分支可设置不同类型。当前类型有选中标记。
- 类型切换按真实节点尺寸递归计算完整子树边界，左右展开将直属分支交替放在两侧，纵向结构将同级分支排在一行。以最外层结构根的位置为锚点，嵌套类型及相关同级分支一并避让。普通兄弟顺序保持不变。
- 已指定类型的分支，点击加号或 Tab/Enter 创建会遵循结构并在预览位置进入标题输入。手工拉线指定落点继续保留自由位置。拖入/重排结构分支后重新按该结构排布；自由拖动不强制复位。
- 长标题改名、图片等尺寸变化时重新计算结构，基础父子连线按实际方位连接节点边缘。
- 沿用节点位置过渡与减少动态效果；类型切换保持当前缩放，选中节点出视野时沿用自动定位，不自动适配全图。

本次只实现上述五种排列，不声称已经实现 Xmind 全部结构（鱼骨图、矩阵、时间轴等）。参考：[Xmind 官方结构说明](https://xmind.com/user-guide/structure-new)。后续方向交互已补齐：粘贴到节点按目标结构排布；空白处粘贴和手工落点保留自由放置。详见 [方向交互](TECH_知识画布方向交互.md)。

## 数据和撤销

- `canvas_data.structure` 保存可选排列类型，未设置的旧节点继续沿用原有布局。复制快照保留类型。
- `update_canvas_data` 已支持一次事务写元数据与多节点位置；类型切换直接复用。新增带类型主题或向已有结构添加主题复用 `create_template` 单节点创建路径，并在同一事务写入相关位置及同级顺序，整体一次撤销/恢复。
- 新增迁移 319；没有修改已应用的 305/306 或既有迁移。权限、容器/节点修订校验与未知结果回执核对继续有效。新增可选字段不改变旧模板命令的回执序列化，避免旧客户端重试不兼容。
- 生产尚未应用迁移；不部署、不提交、不合并。
