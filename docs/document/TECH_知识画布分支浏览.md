# 知识画布分支浏览

## 行为与入口

- 工具条和右键菜单增加“展开全部后代”“折叠全部后代”“回到中心主题”。可编辑、只读空间均可使用；不修改知识资料，不占用画布撤销历史。
- 选中分支时递归处理所选分支，包含已经隐藏的深层后代；未选中时处理当前空间的所有根分支。其他空间的折叠状态保持不变。展开与折叠是明确的两个动作，重复操作保持相同结果。
- 折叠时若选区落入隐藏后代，会映射到最外层可见的折叠祖先；重叠的多选去重，不保留隐藏选中节点。关联线选择清除，焦点返回画布。展开恢复全部层级，不仅打开第一层。
- 回到中心主题：沿当前所选节点的父级找到根主题；选中概要时回到其覆盖分支的根主题；无选中时使用当前空间排序最前的普通根主题。以实际节点尺寸居中，保持缩放，保留“返回视野”入口。不会为了定位而展开无关分支。
- Mac / Windows 共用画布快捷键：Alt/Option+Shift+↑ 折叠全部后代，Alt/Option+Shift+↓ 展开全部后代，Home 回到中心主题（Mac 键盘通常为 Fn+←）。只在画布/目录导航域接管，文字编辑、输入法组合期间和弹窗不接管。工具条自身的 Home 继续定位到首个按钮。
- 不绑定 ⌘R / Ctrl+R、浏览器标签页切换或刷新组合键。快捷键与 Xmind 桌面不同之处是适应网页环境的有意选择；功能语义保持一致。

## 实现边界

`branchBrowsing.ts` 提供带空间隔离、循环保护的图遍历、选区归一化、中心主题解析和视野计算。页面复用现有 presence 和 view motion，开启减少动态效果时直接切换最终状态；正常动画可中途反向接续。保存期间允许浏览，通过 browseEpoch 防止保存完成抢回视野和选择；编辑草稿、拖动或框选期间不切换浏览状态。

本次仅改前端，无新后端命令、数据库迁移、依赖或生产操作。
