# 知识来源一致性校验

已授权范围：在自动整理保存前和知识问答展示前接入公共校验。仅本地实现及复验，不部署。

根因：原有校验只检查结构及引用标识，生成摘要会参与后续汇总，且候选回答在最终引用校正前已流式发出。不能以引用合法代替语义支持，不能通过继续添加针对业务案例的提示词解决。

机制：统一 grounding 服务接收候选项、问题/职责和经服务端授权的原文事实。语义审查返回每项支持性、相关性和逐字原文证据；程序严格核验项覆盖、布尔类型、来源白名单及证据实际存在。原文、导航元数据和程序算术核验保留不同来源类型；元数据只支持位置/主题，不证明业务步骤。模型审查仍可能误判，不视为零幻觉证明。

整理：模型生成与格式纠正共享最多两次候选生成；合格候选还须通过语义和证据校验。自动标签仅是导航分类，不作为事实证据，继续保留原数量/长度/类型校验；不因主题同义词与原文字面不一致而拦截整篇资料。服务端附加已校验的证据片段，随现有 sections/chunks JSON 保存，不增加数据库表。上层摘要只能以原始正文、原始提取片段和已校验的原文证据支持事实；旧的无校验摘要不能单独证明业务规则。候选两次仍未通过时，不保存被拒绝的摘要，程序仅逐字复制原文为明确标注“自动整理未通过核验”的摘录，记录 grounding_mode=extractive_fallback，coverage=partial；自动标签为空。该状态不是生成通过，原始 source chunks 仍保留。源文本已准备而生成/审查服务故障时，仅回退原文并记录 service_unavailable，不能发布未审查候选；格式两次仍不合格时也仅保留明确标注的原文摘录，记录 invalid_structure；不能将清空非法标签或改写坏 JSON 后当作生成通过。媒体源不能取得、权限/来源变化及未知程序错误仍保留失败/既有重试或中止，不转换成可发布候选。缓存策略版本升级，既有资料需重新入队后重建。

问答：只使用本次固定快照实际读取的资料，不扩大授权范围。原始文字和 OCR 源分片可直接提供事实，自动章节需追溯来源或服务端已校验证据。启用知识上下文的模型回合暂存叙述和思考，不写入增量输出或检查点；工具进度仍可展示。最终候选统一校验，通过后展示；不合格最多纠正一次再校验，无法确认或服务异常时只显示明确的核验失败说明及有界原文摘录。引用标签统一为“来源”，避免在链接标签中夹带未核验的业务断言；原始来源名保留在实际读取来源清单。达到工具预算后的总结也走同一校验入口。无知识读取并不自动代表普通对话：自动范围内先做轻量意图检查，只有明确不依赖企业资料的普通回复才能跳过全文语义核验；企业断言、检查失败或不确定时不给无依据候选放行。已有知识工具读取/检索尝试而未取得正文时直接明确证据不足。

约束：每次模型发送前后及结果展示前重新核验权限/固定版本。审查源文本总计 12 万字、候选 4 万字、160 项；单次检查总超时 40 秒，失败不能放行原候选。检查项覆盖或逐字引用格式不合格时最多纠正一次检查结果，不能将否定结论自动改判为通过。不会将部分检查当作完整检查。新增模型调用记录独立 usage 指标，实测延迟和误拦截。

验证：合成资料覆盖无依据费用含义、数字/单位改变、否定与例外丢失、无效/遗漏检查项、伪造证据、审查失败、纠正失败、权限中途变化、旧摘要污染和流式提前泄漏；真实培训文件重新整理及问答。保留旧失败证据，不能改写预设正确答案制造通过。

回滚：回退本次 Python 机制和配置版本；不修改人工正文、固定原件或画布历史，不自动删除旧生成版本。未经校验输出不得作为故障时的兜底。

算术边界：仅当用户明确要求算术核对/计算时，程序从已读原文中识别带等号的有限数字表达式，通过白名单 AST 和 Decimal（28位精度）核算，禁止 eval、调用、幂运算和任意代码。核算结果以 calculation 类型独立提供；它不覆盖原文结果、不赋予成本/运费等业务含义，失败回退时也不能标成“原文”。这不支持任意复杂公式、跨表统计或全业务规则形式化证明。

权限和读取边界：在现有 kb_retrieval_states JSON 内保存本轮真实阅读范围及 context 模式，恢复后仍按这些范围构造证据；不能拿整个知识库给审查器“补证据”。来源服务检查固定版本与权限，审查请求前后及展示前再检查；用户取消/暂停会取消正在等待的审查，不发出草稿。

已知取舍：有知识上下文的回合先暂存当前叙述，即使自动普通对话最终跳过全文语义检查，也不再逐 token 展示该回合的草稿，并有一次意图判断开销。纯非知识回合原有流式行为不变。核验服务继续使用配置的 qwen 模型，独立调用不等于独立模型；其误判需通过留出案例和真实资料记录。新增核验 token 单独记录，不混入不同主模型的计费 token，也不改变现有积分收费策略。

工具链边界：源文本缺失时，意图检查可接收本轮服务器记录的已完成其他工具名称（不接受模型自称已执行）。只依赖相应实时业务工具结果的回复仍属于原业务工具链，不标成知识核验通过；调用任何工具都不能替代公司制度/培训文档的证据。混合知识和其他数据的回复仍可能回退原文，本轮不宣称对所有业务工具的数据真实性做了统一验证。

历史展示：文档接口根据服务端校验版本计算 verification=manual/verified/extractive/unverified，目录和历史来源面板明确提示未核验旧整理及原文回退；不把旧数据直接涂成已核验，也不修改人工正文。上线前需受控重建存量旧整理，本轮只重建隔离测试项目。

证据回放：审查时不能仅以模型选择的短引文代替完整原文上下文。程序会沿已读章节声明的 source_refs，在同一冻结 generation 内回放对应原始 source chunks，逐项授权并记录真实阅读范围；不重新搜索其他分支。旧 child 摘要无原始来源标记时不能自证。证据来源键必须来自本次授权的原始资料集合（导航元数据除外）；程序按实际核验证据重建章节 source_refs，再次检查章节结构与重复标识。历史已核验章节的展示引用同样以实际证据校正，不盲信模型最初声明。审查额外原文同样受12万字总上限限制。
