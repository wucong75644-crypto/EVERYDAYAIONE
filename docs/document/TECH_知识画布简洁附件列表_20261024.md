# 简洁附件列表与节点附件摘要（2026-10-24）

用户确认设计预览后授权实施：节点直接显示绑定文件，侧栏只展示简洁附件行，点击直接预览；添加入口和低频管理操作收进菜单。无部署授权。

## 行为

节点显示前两项附件的缩略图/类型图标、名称、总数，文件资料按钮带数量；完整名称通过悬停查看。点击摘要直接使用公共 PreviewHost 读取对应固定版本，不打开设置或要求先进入文件面板。打开附件会选中所属节点，避免后续画布操作目标不一致。图片已有“作为节点图片”的显示保留，普通附件与节点图片语义不合并。

侧栏标题“文件资料 · 数量”、所属节点、刷新图标和“＋添加”；每行只显示缩略图/类型、名称、类型/大小/版本与“⋯”。点击整行预览。管理菜单提供下载、更新版本、历史版本和移除。历史版本控件只按需展开；移除需确认，并明确不会删除源文件或其他节点引用。只读用户可预览、下载和历史查看，没有写入控件。保留文件读取取消、Blob释放、原操作编号重试及权限/版本冲突保护。预览关闭回到原入口；面板关闭返回画布。

添加菜单包含上传文件、从工作区选择、引用其他节点文件。工作区选择器复用 listWorkspace，支持进入文件夹和返回上级，选择文件即创建固定快照，不再手填路径；20MB限制仍有效。文件引用继续显式选择来源、文件和固定版本。

## 实施

Repository.canvas 在已有文件协议存在时，用一次权限作用域内批量查询为当前最多500个节点补充 attachments={total,items前两项}。采用现有RLS与 public.kb_file_version，输出版本先经 public_version 过滤，禁止携带私有存储所属者或路径。未增加数据库迁移。查询前核验现有三参数版本函数，兼容尚无V2文件协议的库。

新组件 KnowledgeAttachmentUI 提供附件摘要、私有缩略图、直接固定版本预览和工作区选择器；filePresentation 格式化文件信息。缩略图按可见区域延迟读取，超过2MB使用类型图标，防止打开画布即批量下载大图片；读取仍走私有固定版本接口，卸载/版本变化取消请求并释放URL。节点虚拟尺寸计入摘要高度。

文件修改成功后即时更新节点摘要并刷新场景/历史，保持容器版本一致；慢初始列表不能覆盖写入结果。正文未保存时不打开另一条文件写入流程。保留先前未发布的四边调尺寸、正文自动保存和图片查看器复用改动。
