## 统一规则

使用 `structureDirection.ts` 统一决定子级方向、节点入边方向和同级排序轴。向右/向左结构的同级沿纵轴排列；向下/向上结构的同级沿横轴排列。嵌套结构的子级端口遵循自身类型，同级端口与排序遵循父级结构。左右展开按所在侧处理，已有概要/外框成员在切换类型时不被拆到两侧。

1. 加号和折叠圆点根据方向放置；拉线预览与原位创建草稿线从实际端口出发。浮动节点工具条避让端口，减少动态效果沿用统一设置。
2. 方向键沿分支方向展开/进入子级，反向收起/返回父级，同级按其排列轴导航；左右展开根可分别进入左右分支。更新提示文字，不再固定提示左右键代表父子。
3. 拖动排序按同级轴判断前后，横向同级显示竖直插入线。普通分支和多分支共用规划；结构重排不再先经过旧的纵向挤压，保持结构根锚点和原有权限/版本检查。
4. 概要与普通子主题区分排布，括号随方向旋转；概要主题及其后代预留完整范围，自动避让其他节点。原父子关系不变。左右展开的多选按同一父级、同一方向拆分概要/外框。
5. 概要与外框手柄沿同级轴拖动，横向范围使用左右键，纵向范围使用上下键。预览、松手保存、Esc 取消及指针取消沿用原机制。弹窗候选同样限定所在方向，不混入概要主题。保存后恢复画布焦点，使撤销立即可用；用户已转移浏览目标时不抢焦点。
6. 粘贴到节点按目标结构排布完整分支，保留复制内容快照和节点自己的结构覆盖；剪切同步重排原位置及目标位置。空白处粘贴继续保留点击落点。目标已有节点位置变化、复制出来的各节点位置在同一命令内保存，一次撤销/重做整体恢复。
