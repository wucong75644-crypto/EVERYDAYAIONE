# 知识画布自由摆放智能对齐

## 行为

- 仅自由摆放启用智能对齐。父子层级落点、同级插入位置优先，进入这些落点时停止自由吸附，不修改原层级规则。
- 参照当前空间、当前视野附近且未被折叠隐藏的静止节点，提供水平/垂直边缘及中心对齐线。移动节点和它的后代不互相充当参照。
- 同一视觉行/列的相邻参照节点支持插入居中等距，以及沿已有间距向前/后延伸；显示两段相等间距及画布像素数。使用真实卡片尺寸，支持不同宽度。
- 吸附以屏幕距离计算：6 像素内捕获，已有目标在 10 像素内保持，减少临界位置跳动。放大缩小不改变屏幕手感。
- 多选以可见移动节点的整体包围盒吸附；整条分支（包含隐藏后代）使用同一平移量，保持相对位置。
- 拖动中按住 Shift 临时关闭吸附，松开立即重新判断，无需再次移动鼠标。Esc、窗口失焦、指针取消或无效落点沿用原取消/回滚流程，清除辅助线。
- 线条、标尺和文字不接收指针事件，不影响节点命中与布局。反馈跟手显示，不加补间；减少动态效果下保留同样的对齐与吸附能力。

## 保存与历史

`smartGuides.ts` 计算对齐与等距候选、稳定目标和反馈；`SmartGuideOverlay.tsx` 只绘制临时提示。页面在已有自由拖动计划上增加平移修正，不更改 `branchLayout` 的层级规划。

预览、松手、边缘平移及 Shift 切换共用同一个规划入口，松手重新核算最终点位。只有松手时通过既有 `move_branch` / `move_branches` 提交一次；复用权限、对象/布局版本、容器版本、收据核对和撤销重做。失败恢复原位置，不保留临时线条。本次不改后端，不增加迁移或依赖。
