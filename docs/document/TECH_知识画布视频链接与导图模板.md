# 知识画布：视频、网址和导图模板

状态：2026-10-24，本地实现，未部署。沿用当前知识画布任务工作树与既有权限、固定版本、回执和撤销语义。

## 用户操作

- 工具条「节点视频」：上传或选择已有 MP4 的明确版本，在节点显示播放卡片，点击打开页面内播放器。沿用已有附件 20MB 限制；推荐 H.264/AAC 编码。不转码、不生成公开媒体地址。加载或解码失败时显示具体提示；有权限并已成功读取的版本可下载原件。
- 工具条「网页与视频链接」：输入网址、显示名称和自动/视频/普通网页方式。普通网址用新标签页打开，保留画布。HTTPS 视频直链（MP4/WebM/OGV）尝试原生播放器；识别 Bilibili BV、YouTube 常见视频地址、Vimeo 数字视频地址后，使用固定官方域名的嵌入地址。短链、未知平台、HTTP 视频及其他网址保留跳转入口。
- 外部播放器只在用户点击预览后加载，默认不自动播放。预览中始终保留「前往原平台观看」，供登录、地域、源站限制或网络故障时使用。不以 iframe 的 load 事件冒充播放成功，不自动把用户带离画布。不抓取分享页、不搬运远程视频、不代理任意外网请求。外部链接不具有上传文件的内容固定保证。
- 右键菜单「创建主题 ›」直接提供默认主题、年度总结、项目计划、会议记录、售后流程。空白处右键选择模板时创建独立主题树；节点上右键选择模板时创建该节点的子主题树。不再提供独立工具条模板按钮、预览弹窗或额外父节点选择；创建后可按原有方式改名。生成的是普通可编辑节点，没有给用户写入真实业务结论或强制创建任务指派。

## 数据与调用链

新增迁移 `318_knowledge_canvas_media_templates.sql`，不修改已应用的迁移。

`CanvasData.video={binding_id,revision,title}` 引用本节点的有效 MP4 绑定与固定版本；`CanvasData.link={url,title,kind}` 只接收无嵌入凭据、无控制字符的 HTTP/HTTPS URL。前端再次解析 URL，拒绝危险协议及伪装平台域名；iframe 地址由受控规则生成，不直接使用用户提供的 iframe HTML。

- 视频/链接编辑继续调用 `update_canvas_data`，共享容器、布局版本校验、幂等回执和历史；媒体卡片引起的必要布局避让与元数据同一事务提交。文件上传本身仍保留为文件资料，撤销视频呈现不会删除文件。
- `create_template` 在容器写权限、容器版本和父主题归属校验后，在同一事务创建最多 200 个主题及初始版本、位置。父索引须先于子索引，只有一个根；不允许循环、跨空间父主题或部分成功。一次撤销/重做作用于整套模板。
- 视频复制快照保留所选文件版本，粘贴时重建新绑定并映射到副本，后续源文件更新不影响副本；网址按内容快照复制。视频读取继续使用现有鉴权接口，读取前后均检查当前权限。关闭播放器中止请求并释放 Blob URL。
- 上传结果未知时，编辑器锁定并使用相同文件和 command_id 核对，不盲目创建第二份上传。模板/元数据结果未知时沿用现有保存回执核对入口；已确认失败保留用户输入。编辑弹窗阻止误触离页；目前未新增此类弹窗的持久草稿恢复。
- CSP 保留现有防护，明确允许三个官方视频播放器域名；媒体允许 HTTPS 来源和鉴权读取产生的 Blob。没有添加任意网站 iframe 或任意脚本来源。模板及播放器沿用现有减少动态效果设置和焦点归还。

## 验证边界

隔离 loopback PostgreSQL 验证模板原子性、重放、权限、版本冲突、撤销恢复、媒体固定版本及复制重映射。前端覆盖 URL/域名校验、失败回退、卡片与播放器、未知上传重试、模板结构和界面链路、Mac/Windows 修饰键及输入框原生撤销。

本地浏览器用 3 秒 H.264 合成 MP4 验证真实解码和页面内播放，未上传真实业务资料。平台嵌入受源站限制，未声称所有平台/账号/地区均可播放。Windows 原生浏览器和系统剪贴板未实机验收。首批不含视频转码、大文件流式上传、HLS、短链解析和远程下载。
