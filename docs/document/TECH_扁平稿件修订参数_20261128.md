模型只提交以下形状，修改字段与item_index并列：

```json
{
  "base": {"content_ref": "从真实读取回执复制", "item_index": 3},
  "updates": [{"item_index": 3, "options": {"aspect_ratio": "1:1", "resolution": "1K"},
    "prompt": {"positive": "产品居中展示，柔和自然光，输出正方形1K画布。"}}],
  "continue_execution": false

```

此例仅示意结构；真实目标有必改展示章节时必须同步presentation，原稿未改细节由实际读取和章节合并保留，不能复制示例替代原稿。新建document、历史message_source恢复、图片image_ref编辑、视频和文件交付不改。

content_update_wire在原模型边界统一完成schema/案例最终扁平投影和输入还原。后台ItemUpdate(item_index,item)是既有领域内存/恢复记录，不是第二种公开接口。模型旧嵌套或混合写法明确拒绝，不猜格式、不兜底接受；已认证NativeToolCall仍按原始参数/哈希校验和恢复，不再经过模型解码。

schema条件规则同步移到扁平更新对象，至少item_index加一个真实修改字段；空补丁、null、未知字段、错误编号、未读、旧版本及越界权限继续拒绝。没有目录的schema引用也同步展开/更新，不能在$defs留下旧ItemUpdate结构。没有目录时结构化保存必须保留边界转换结果，不能解码后丢弃；旧任务控制和其他工具仍用原错误/执行职责。
