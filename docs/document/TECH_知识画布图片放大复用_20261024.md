# 节点图片点击放大与公共查看器复用（2026-10-24）

用户反馈点击节点内图片打开了图片设置，希望点击直接放大，并核对上传、存储和查看器是否复用工作区。

## 实际链路

CanvasNodeImage 原 onEdit 指向 openVisual(image)，是错误入口。缩略图已通过 knowledgeFilesApi.content(object_id,binding_id,revision) 读取固定版本，返回私有 Blob。上传使用 knowledgeFilesApi.upload → knowledge_files.persist_upload，复用 workspace_coordination 的 receive_workspace_upload、finish_file_io、workspace_lock，使用 file_workspace_root；文件落在 .knowledge-versions/{企业或personal}/{owner}/{version}/content，不在普通用户/渠道工作区，也不参与普通工作区OSS同步。工作区文件导入使用 /files/from-workspace，经 FileExecutor 安全路径和前后版本核验后再生成不可变副本。这是共用基础设施与独立版本语义，并非同一普通工作区文件，不能去掉权限、固定版本或历史读取保障。

工作区预览 imageAdapter 已使用公共 components/chat/media/ImagePreviewModal。此次直接复用同一个公共组件和已有缩略图 Blob URL，不增加公开链接、不再请求另一套源文件、不触发写命令。支持放大、缩小、双击、拖动、重置、下载、Esc关闭，沿用画布减少动态效果适配。图片设置继续保留节点工具条“节点图片”入口；图片加载失败时仅重试读取，不进入设置。

## 实施边界

预览状态放在画布根部，避免缩放 world 层或节点事件处理影响公共Portal。预览打开时沿用画布浏览/历史阻断，关闭恢复画布焦点。绑定版本变化或节点消失时关闭预览，账号/企业切换立即按identity隐藏并清理。继续沿用缩略图请求取消及Blob URL释放，不改上传、存储、绑定或数据库逻辑。

浏览器验证发现公共图片查看器的遮罩背景只存在于CSS关键帧，画布禁用旧动画后会变透明。为公共组件增加相同深色的静态底色，原非画布动画仍保留，补充画布范围测试断言。
