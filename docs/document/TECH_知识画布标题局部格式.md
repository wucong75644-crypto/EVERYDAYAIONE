# 知识画布标题局部格式与对齐

本轮仅开发与本地验证，不发布生产。

后续编辑一致性 P1 已将 textarea + 独立预览替换为所见即所得编辑，补齐实际继承回显、编辑历史与选区恢复、格式作用范围。当前交互以 `TECH_知识画布编辑与独立元素P1.md` 为准，下文保留初版实现记录。

## 交互

双击标题、F2 或原有改名入口打开原位编辑。保留 textarea 的选区、换行和中文输入机制；选中文字后可切换粗体、斜体、颜色及 10–48 号字，下方即时显示格式预览。左/中/右对齐作用于整个标题，不改变主题结构或分支方向。工具栏切换保留选区，选区内一致的颜色、字号和粗斜体状态可回显。

Mac ⌘B/⌘I、Windows Ctrl+B/Ctrl+I 修改当前选区。输入法组合期间不执行格式、提交等快捷键。编辑内 ⌘/Ctrl+Z 撤销文字或格式，Mac ⇧⌘Z、Windows Ctrl+Y/Ctrl+Shift+Z 重做；确认后作为一次画布历史操作整体撤销恢复。Esc 放弃本次编辑，点击编辑区外确认；在编辑区内点击格式控件不触发提交。没有选中文字时局部格式控件不修改内容。

局部样式不覆盖整图/层级/节点样式的其他属性。新增文字继承相邻文字格式；直接选中节点打字替换标题时保留对齐、清除旧文字范围格式。保存期间继续修改标题或格式均保留为后续草稿，未知保存结果核对也对照实际提交的文字和格式。

## 数据和事务

`canvas_data.title_format = {align: left|center|right, runs: [{text,bold?,italic?,color?,font_size?}]}`。
使用文本片段而非持久化偏移，避免中文、表情与 JS UTF-16 / 数据库 Unicode 字符数差异。非空 runs 拼接必须等于原始标题；空 runs 表示整体继承。每段纯文本，不接受 HTML/CSS。前端仅生成安全 span，单项格式只作用于选择范围，未指定属性继续继承。

新迁移 324 扩展现有原子命令和画布数据校验。`update_title` 同时提交 title 与 title_format，格式命令要求容器版本，复用对象版本、写权限、回执幂等与原子历史。创建节点/结构主题/插入父主题可一次提交根主题格式（批量子项不接受单独格式）。旧客户端纯文本改名不带格式时清除旧范围数据，避免错误套用旧文字。已有命令未提供新字段时不改变旧回执 payload。

画布快照、复制粘贴、撤销重做沿用完整 canvas_data。字号变化参与实际 DOM 测量和同事务避让/结构重排；无 DOM 回退按最大字号估计，支持已有五种排列。没有新增强制动画，沿用既有减少动态效果设置。未修改已应用迁移，324 尚未应用生产。

## 验证范围

前端覆盖选区粗斜体切换、颜色输入、字号、对齐、中文和表情编辑、HTML 字面量安全渲染、编辑内和画布级撤销重做、Mac/Windows 组合键、保存期间继续修改。后端真实临时 PostgreSQL 覆盖格式/标题同事务、回执重放、权限/版本冲突回滚、非法样式、格式与标题不匹配、创建/模板、复制快照与历史恢复。浏览器使用本地合成资料验证实际选区、控件、预览、保存和整次撤销重做，不访问真实业务数据。

原生 Windows 和系统级中文输入法尚未实机验收；自动测试包含对应组合键和 composition 事件。
