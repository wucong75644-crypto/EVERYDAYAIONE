## 本轮修复与正式回归

1. 定向素材迁移从“图一/图二”的真实语句确定目标，补全明确素材，保留否定、引用文本、歧义和新追加要求的边界；原图/画布错误不再统一抹成临时接口故障。
2. GPT Image 2.5 已登记模型按16像素网格验收最近标准比例，仍记录真实宽高；未声明此协议的模型不放宽，精确像素仍严格匹配，没有裁切、拉伸或变更用户规格。[OpenAI尺寸协议](https://developers.openai.com/api/reference/resources/images/methods/generate)明确要求相应图片模型边长为16的倍数。
3. 只写方案/指令/策划不能授权购买图片：模型工具列表和真实派发同时约束；只有本人真实追加的执行要求可以改变这一状态，原权限上限不变。
4. 主聊天关闭思考传入电商策划子模型；已知强制思考接口在调用和预留前停止。允许配置已注册Qwen进行本地对照，没有自动替换线上默认模型。
5. 当前视觉输入事实与额外读图预算分开，防止从旧失败记录推导“本轮看不到图片”；卖点问答区分可见事实与未证实性能。
6. 用户明确的单一平台冻结到策划输入；多个平台、引用示例和否定要求不随便选择一个；原固定页面参数与保存方案恢复保留。
7. 策划连接中断显示具体中断原因、保留阶段与未提交生图事实，仍禁止未知结果的自动付费重发。
