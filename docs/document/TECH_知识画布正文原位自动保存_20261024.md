# 节点下方正文输入与自动保存（2026-10-24）

用户要求点击展开资料后在节点下方直接输入，输入自动保存，点击空白或右上角关闭，正常状态不显示多余文字。

新增 InlineBodyEditor，位于画布 world 层目标卡片下方，随画布缩放定位；打开时让输入区进入安全视野并聚焦。正常只呈现正文 textarea 和关闭图标，保留无障碍名称、只读限制及键盘 Esc。历史版本入口移至节点右键菜单，使用既有 KnowledgeHistory，只读来源与版本语义不变。

输入停顿500ms合并保存，失焦立即保存，中文输入法组合期间等待确认。复用 save_document 和既有幂等、权限与版本检查。保存中仍能输入，仅用已确认 payload 更新正文基线和期望版本，后续内容继续自动保存，成功不关闭输入区。关闭立即隐藏输入区，同时冲刷未保存内容，确认最新内容保存后才清理编辑状态；失败重新显示输入区和必要错误/重试入口。未知结果只用原命令编号核对，不生成新命令覆盖。冲突草稿不自动重定基线，明确重试仍使用原版本，防止覆盖其他作者内容。

沿用 useCanvasDraft 的离页保护和浏览器持久草稿，账号/企业隔离、恢复权限和版本核验保持有效。未确认写入和未保存正文仍进入草稿，关闭视图不先删除草稿；切换或卸载停止自动保存定时器。正文编辑仍阻止同时执行结构写操作，避免版本竞争。无新增后端契约或迁移。
