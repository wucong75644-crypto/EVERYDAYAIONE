# 2026-11-01 工具派发身份与 NAS 快照生命周期

## 已核实的故障

生产原文件分析失败包含三个独立环节：治理模型的 qwen-turbo 两次限流、qwen-plus 一次输出非法 sheet role；清理快照时 NAS 报 ENOTEMPTY 掩盖治理错误；随后模型尝试 code_execute，被派发前的 TASK_REVISION_SCOPE_DENIED 拒绝，未启动代码执行。

原派发检查通过共享同步 LocalDBClient 调用 SQL，缺少事务级 app.actor_user_id/org_id/access_kind。生产只读检查证实原连接这些值为空，设置当前身份的事务可见真实任务。因此不能通过放宽 RLS、取消检查或给用户扩大权限修复。

NAS 留下的 .nfs 文件由 Conversation Actor 的打开描述符持有。fastexcel 没有公共 close 接口；原 release_cached 只清空 DataFrame，异常栈仍可持有扫描器和读取器。另有 PathB 公式线程 shutdown(wait=False) 以及取消创建扫描器时结果被丢弃的同类生命周期漏洞。

## 修复边界

- 复用 task_database 的不可变事务 Scope，支持同步客户端；原派发检查调用此门面，通过后仅在当前工具实例保留门面，让后续原生准备/收据使用同一 Scope；不更改共享客户端。不修改 SQL、用户/企业权限、运行租约、新消息门禁或防重复执行协议；已有 Scope 与任务不符仍拒绝。
- ExcelReaderLease 只拥有本次打开的 fastexcel 读取器，关闭时释放底层引用，异常栈保留 lease 不再保留文件。扫描器、工厂异常、转换及结构采样均显式结束所有权；外部传入的 reader 不擅自关闭。
- 创建扫描器在线程内登记所有权，取消时先 drain 原 IO，再清理扫描器；扫描器关闭后才释放转换锁。Calamine workbook 显式关闭，PathB 公式线程排空后才能删除快照。可能增加取消时等待在途本地 IO 结束的时间，不增加模型调用。
- 快照复制与源文件内容/版本复核不变；NAS 清理错误单独记录，保留已有业务异常或取消。只有清理失败且没有原异常时仍报失败，不静默声称成功；不删除原文件或有效成果。
- 治理模型统一 qwen3.8-max，关闭额外思考；仍为原 3 次有界尝试、原超时、JSON/schema 校验、原冷却缓存与有效缓存复用。未授权自动追加模型费用。

## 本地验证与限制

使用真实本地 Excel 读取器检查描述符释放，保留异常栈；覆盖正常转换、缓存复用、治理失败、取消创建、ENOTEMPTY 与取消错误优先级。隔离 PostgreSQL 使用原同步连接池复现未携带 Scope 的拒绝，并验证两用户并发、不泄露事务身份、错用户/企业、旧 token 与新消息拦截及上下文保留；复用原文件删除确认、恢复收据和防重复执行验收。

本地使用模型替身且禁用 API 密钥，不产生供应商费用、不生图。实际供应商限流是否缓解不能由模型配置或本地测试保证。生产 NAS 故障不能在本地磁盘完全重现；以生产打开文件证据、真实本地描述符释放和注入 ENOTEMPTY 组成回归证据，发布后只进行无业务副作用检查，不自动重跑用户任务。

工具摘要失败状态和审计日志分区告警是另行发现的问题，本次不改变这些机制，也不据此宣称所有工具失败原因均已消除。回滚沿原 release.sh 受控流程执行，不回滚用户业务数据；本次不新增数据库迁移。

本地最终证据：相关模块361项通过；读取器封装整理后111项通过；最终边界冒烟42项通过（有重叠）。隔离 PostgreSQL 最终58项通过，包含真实同步客户端的原恢复/删除完整流程、确认、原生收据及重复调用复用。发布入口仍须验证最终 SHA 的前后端测试/构建和 readiness；此记录不替代生产业务验收。
