# 知识画布 V3：主对话引用

状态：两批代码与隔离验证已完成；未提交推送，未部署。基座 `1abb9dda626321984f79213665a27aeaeec1029a`。
用户授权两批全部开发与测试；不包含部署、V4 定时推送或 V5 实时协作。

## 完成条件与任务地图

1. 主对话 @ 候选同时支持既有文件和有权访问的知识总分支；结构化引用随消息、乐观状态、请求指纹和历史响应持久保存。每次最多 8 根，严格 schema，不接受 actor/org/snapshot 等权限事实。
2. 主对话首次执行根据持久输入消息建立快照；同一输入任务恢复/重试使用同一快照。重新生成与新消息重新建快照。模型不得通过 params 注入知识授权。入口验证与每次读取均检查当前权限。
3. 统一 Registry/Policy/Dispatcher 接入 outline/search/read/follow_reference，只在有真实知识引用的个人主会话展示；经验 search_knowledge 保持原用途。工具按 root/item/link opaque handle 读取；分页游标绑定根、动作、查询与快照。
4. 冻结正文版本、附件绑定版本、显式规则版本和关系；可见真实引用仅引入被指向对象，不引入其整个项目。循环与资源上限显式拒绝。保存 audit receipts 区分目录、片段、部分正文、完整正文。
5. 回答引用工具提供的版本来源链接，返回画布并定位对应节点和历史版本；缺失/撤权时明确不可用。未处理、截断或不支持提取的附件不能冒充完整读取。
6. 需要文件分析时，只物化当前 actor 私有任务目录内的已授权副本；每次继续使用前复核绑定，不开放上传者 Workspace 或其他项目。

## 实现与自审记录（2026-10-23）

- 主对话引用保存为独立 `knowledge_refs`，不混入正文、附件或模型参数；重试从原始用户消息恢复引用，重新生成新用户输入获取新快照。`regenerate_single` 沿用既有媒体语义，不提供新的知识问答入口。
- Actor/Web 共用快照工具；只有入口服务端写入的 `_knowledge_refs_required` 才激活，普通聊天不查询知识库；客户端同名前缀参数先移除。已有 Actor 持久参数会保留该标记。
- 自审发现并修复普通聊天被额外数据库检查阻断的问题；原有 Web/Actor 模型失败重试、部分输出、失去所有权和计费集成测试均已恢复通过。
- 跟随真实关联只引入目标本身与其文件，以及显式适用规则；冻结祖先规则与空间通用规则，不引入目标下的普通兄弟文档。规则来源、截断状态和冲突判断要求随读取结果返回。
- 临时文件只写当前 actor 的 `knowledge-inputs/<snapshot>/<handle>/`，不开放上传者目录。结束/异常时删除该快照已知文件（不递归删除其他文件）；恢复时重新授权和物化。进程被强制终止时 finally 无法执行，可能留下当时已授权的私有副本；不承诺撤回已经下载或复制的内容。
- 来源尾注由实际读取回执生成；保留模型原正文，在 flush 前加入来源。正文/附件旧版本都通过当前 ACL 读取；版本不存在或撤权时拒绝，不替换为最新。
- 305 迁移在临时 PostgreSQL 上以真实 runtime 角色测试，覆盖 FORCE RLS、跨账号/企业隔离、绑定移除、快照复用、游标篡改。回执增加 snapshot/item/state 索引。

## 真实模型补充联调

用户明确授权使用现有 `.env` 模型配置后，仅在子进程内白名单加载模型 Key/地址；未复制应用环境文件、未加载数据库/Redis/OSS/SSH 配置、未输出密钥。独立临时数据库、合成资料和运行时 RLS 继续保留。

- 使用实际 `qwen3.8-max` / DashScope 适配器、四个知识工具 schema、真实 ToolExecutor 知识处理器、快照和读取回执，模型自主决定导航/读取；禁止其他工具。四场景顺序完成，共 73.82 秒。
- 初始：读取合成 TXT 附件 `RET-1023-TEST`，签收 8 天，7 天规则，模型结论不能退货。
- 同一输入重试：修改当前规则为 30 天后，仍复用原快照并依据 7 天旧规则回答。
- 新输入：新快照读取规则 revision 2，依据 30 天规则判定可以退货。
- 冲突：另加同等有效的 7 天拒绝规则，模型列出两版本冲突并要求人工确认优先级，不擅自给出确定结论。
- 模型可能漏写链接；最终回答使用与执行内核相同的回执来源尾注补齐固定版本链接。定向内核测试另验证原答案保留、尾注进入输出事件并在 flush 前完成。模型错误调用（例如对非文件要求物化）通过受控错误结果返回供其纠正，不扩大权限。
- 原始模型文本、工具参数/结果、来源与快照 ID 保存在忽略目录 `model-initial.json`、`model-replay.json`、`model-new-turn.json`、`model-conflict.json`；测试入口与结果为 `test_real_model_v3.py`、`real-model.log`，不进入默认 CI、不自动消耗模型额度。
- 这是提供商 + 知识工具链的真实联调，不是完整生产 Web/Actor/WS 浏览器测试。未测试所有提供商、多轮超长目录、OCR、音视频或任意 Office 原件分析；这些不在本次已通过证据范围。
