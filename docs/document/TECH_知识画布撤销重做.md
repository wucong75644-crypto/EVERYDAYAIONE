# 知识画布撤销与重做

2026-10-23：授权覆盖创建、改名、拉线关联、父子调整、同级排序、整支移动；兼容 Mac/Windows，不部署。

服务器在正常写入所在事务中记录差异，客户端不提交“旧值”。308 新增 actor/org 隔离的历史栈与容器版本头。每步保留变更对象的标题、父级、顺序、位置和正文版本引用，以及关联差异，不复制附件或正文。最近 100 步；刷新后仍可继续。新写入丢弃重做分支。非撤销范围的正文、成员或外部文件写入不能被旧撤销覆盖。

undo_canvas/redo_canvas 请求指定顶端历史 ID，服务端复核当前身份、空间写权限、栈顶和容器版本头后在同一事务恢复差异、生成新内容/布局版本、更新审计与幂等回执。恢复失败整体回滚；网络结果未知时沿用同一命令 ID 重试。历史栈每次操作随刷新读取；不持有跨账号缓存。

创建撤销不删除真实内容或文件：新增 undo_hidden 标记，从当前画布、目录、搜索、候选和新快照中排除；已有快照、固定版本和来源直读仍按当前 ACL 可访问。项目创建撤销同时隐藏该容器；重做使用原对象 UUID 恢复。历史来源在节点不再位于当前画布时可独立显示。

同一 actor 在多个页面的栈顶 ID 及权限均需复核；任何未纳入该栈的空间写入会导致版本头不符，禁止恢复。新动作开始时丢弃该空间失效旧栈。正常追加的本地操作与连续撤销/重做会更新版本头，因此不会因自身递增版本而错误阻塞。

输入/正文编辑时保留原生文字撤销。画布 Mac ⌘Z/⇧⌘Z；Windows Ctrl+Z、Ctrl+Y、Ctrl+Shift+Z；工具栏提供带操作名称的按钮。保存中、编辑草稿中或拖动中不触发持久画布撤销。冲突和撤权明确反馈。

验证使用新建 loopback PostgreSQL 覆盖两种实际应用角色、所有操作、连续撤销重做、分支清空、过期/跨账号/撤权拒绝、幂等、隐藏创建及历史来源/快照。前端检查快捷键、输入法、输入框原生撤销、保存失败和刷新。旧迁移不改；回滚应用保留新表/标记/版本，不能让旧应用重新暴露已撤销创建的内容，需先恢复候选或保留兼容过滤。
