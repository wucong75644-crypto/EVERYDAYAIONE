# 知识画布主题录入

## 行为

- 单选可编辑节点后直接打字，以输入内容替换标题；保留首字并把光标放在末尾。F2、双击维持已有编辑入口。快捷键、输入框内输入和粘贴保持原义。组合输入期间不提交，避免中文选词 Enter 误保存。
- 插入父主题：Mac ⌘Enter、Windows Ctrl+Enter，或右键菜单/工具条。原节点及其后代、正文和文件身份保持不变，新主题占据原层级位置。概要/外框成员引用跟随新父主题，原有备注等仍属于原节点。
- 多行纯文本粘贴：单选节点时添加子主题；未选中时创建独立主题树。空行忽略，Tab/空格缩进表示层级，同层表示同级。拒绝不一致缩进及跳级。最多 200 节点，每标题最多 200 字符，超限明确报错，不截断或部分创建。内部复制分支及图片保留原粘贴链路。
- 新节点和父主题按所在主题的右向、左向、双向、向下、向上排列方式布局。每次批量创建或插入父主题各占一次撤销步骤。

## 实现与安全

前端 `topicEntry.ts` 负责文本解析和布局规划，页面负责输入法、焦点、入口和历史定位。工具条使用非模态菜单，关闭后优先归还行内编辑焦点，避免失焦误保存。

新增 `create_topics` 和 `insert_parent` 命令，由新迁移 321 提供事务实现。检查容器、对象、布局版本及写权限，布局移动与创建/换父一次提交；失败整体回滚。沿用命令收据，网络结果未知时核对同一请求，不重复创建。没有修改已应用迁移。
