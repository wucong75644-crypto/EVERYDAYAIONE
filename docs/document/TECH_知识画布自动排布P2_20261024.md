## 操作与语义

在画布工具条的“全图样式”里设置自动排布，三个开关可独立组合：

- 按左右子树实际高度自动平衡：仅对左右思维导图分配左右分支。测量完整后代、图片等内容、概要子树以及外框范围；沿同级顺序把完整分组放到累计高度较小的一侧。概要和交叠外框覆盖的同级范围作为整体，保持原父子关系和同级顺序。采用确定性的贪心分配，非全局最优排列求解。
- 整图紧凑布局：保留中心主题位置，压缩所有方向的同级及父子间距；概要保留独立空间。没有显式排列类型的树按默认向右排列。多个独立中心主题各自保持锚点。
- 同层等宽：当前空间内同一逻辑深度采用该层最宽主题的有效宽度。只派生显示尺寸，不覆盖节点保存的自定义宽度，关闭即可恢复。长标题、内容图片、字体及层级样式仍参与测量。

设置保存在当前空间 `canvas_theme.layout`，后续创建、改名、插入父主题、粘贴、调整层级、键盘排序以及内容变化的布局调用继续使用设置。旧空间不带 layout 时保持原设置语义。

## 保存与恢复

沿用 `update_map_theme`，设置、样式覆盖及节点位置由同一事务和同一条历史记录更新。后端检查空间权限、容器和节点布局版本；失败整体回滚，未知结果沿用原命令 ID 核对。旧主题序列化不额外注入空 layout。不需要新迁移，未修改任何已应用迁移。

沿用画布历史及动态反馈机制：Mac Cmd+Z / Cmd+Shift+Z，Windows Ctrl+Z / Ctrl+Y（也支持 Ctrl+Shift+Z）；遵循系统减少动态效果。排布开关使用标准可聚焦复选框，无新增快捷键冲突。草稿、只读及保存中锁定沿用全图样式弹窗。
