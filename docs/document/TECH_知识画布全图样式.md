# 知识画布全图样式

## 范围与规则

新增工具条“全图样式”，设置当前空间的整图配色、背景、点阵网格、全局字体和字号。海洋、森林、日落、简约灰四套配色按主分支分色，后代沿用分支色；背景可跟随应用或自定义颜色。字体为系统、无衬线、衬线、等宽，采用 Mac/Windows 字体回退，不下载字体。

样式优先级：节点自定义 > 对应视觉层级规则 > 全图设置 > 应用默认。默认保留自定义节点；勾选覆盖时只清除节点样式，不改变正文、文件、节点宽度、任务或结构。清除层级规则、恢复全图默认是独立设置，不会暗中删除节点内容。

单选节点后可在面板中“更新所选节点所在层级”：使用该节点当前显示样式建立层级规则，同时清除同层节点的显式样式，让它们统一继承。根为第 1 层，概要按所覆盖分支的视觉深度计算。规则支持前 32 层，覆盖当前空间所有根分支的相同深度；新建主题同样继承。此操作和整图应用各为一个历史步骤。

面板内有预览，应用前不改变实际画布。字号/字体变化按真实节点重新测量，必要布局与样式一起保存；只换背景/颜色不重排。局部样式编辑和格式刷读取当前继承效果，避免打开后跳回旧字体。批量创建和父主题插入考虑继承字号，减少新节点重叠。

## 数据与事务

- 新迁移 `323_knowledge_map_theme.sql`：`kb_containers.canvas_theme`，默认空对象，旧空间外观保持原样。没有改动已应用迁移。
- 新命令 `update_map_theme`：容器版本、样式重置的布局版本和布局移动版本全部检查，一次事务保存。样式重置参数只能传 style，不能借此改正文、文件或其他 canvas_data。
- 画布状态/历史差量包含空间主题，撤销重做恢复主题、显式样式和坐标。兼容没有 theme 字段的旧历史，旧历史不会覆盖当前主题。沿用角色隔离、命令收据、重复请求核对及跨用户版本保护。
- 主题设置不写入对象知识版本；布局与内容语义继续分离。复制分支保留原有内容快照，目标空间主题是目标空间的继承规则。
- 草稿沿用账号/企业隔离存储，恢复时检查空间权限和版本；保存结果未知保留原请求编号，可在弹窗内核对，不重复应用。恢复成功拿到草稿租约后才打开编辑器。
- 普通模式使用已有面板/布局动态；减少动态效果时直接切换最终位置和面板状态，不新增色彩闪烁或装饰动画。
