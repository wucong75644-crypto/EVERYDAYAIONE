# 知识画布分支拖动

2026-10-23，用户授权父子调整、同级排序、整支移动及清晰落点提示；不部署。

现有 reparent 与 move_nodes 分开执行，无法原子保存；节点按 UUID 返回，缺少持久同级顺序。本次新增 307，不改已应用迁移；增加 kb_objects.sort_order、插入/换父时追加顺序触发器，以及 kb_apply_branch_command。旧命令保持兼容。

新 move_branch 命令携带源对象版本、容器版本、target_id、placement（free/child/before/after）以及受影响节点位置和布局版本。服务端在容器锁内复查权限、源/目标、循环、完整子树、布局版本与同空间边界，再原子更新父级（生成新正文版本）、同级顺序、全部位置、容器版本、审计与幂等回执。排序属于当前组织状态，历史正文/文件与已有快照不改写。容器版本冲突拒绝整个拖动，前端刷新恢复真实状态；无部分成功。

前端拖动收集整棵子树（含折叠后代），预览整支位移。中部落点为移入，顶部/底部为插前/插后，空白为自由移动（父级和顺序保留）。目标为自身后代、其他空间或只读时拒绝；移入自动展开。结构落点使用子树边界分配位置并下移受影响同级分支，尽量避免覆盖；自由移动保留用户明确落点。Esc/失焦/取消只撤销本次预览。目录按持久 sort_order 排列，旧数据按原坐标初始化，新节点追加。

验证包括独立 loopback PostgreSQL 真角色：迁移、循环/越权拒绝、版本冲突原子回滚、排序与追加、幂等；前端几何、整支移动、落点、取消、保存和刷新。无生产连接。回滚应用先停止新拖动写入；数据库保留新增列和函数，不删除历史数据，不回滚 305/306。
