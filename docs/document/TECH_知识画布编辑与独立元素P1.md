# 知识画布编辑与独立元素 P1

本轮接续现有任务工作树，不发布生产。范围为用户确认的五项：文字格式继承、所见即所得标题、编辑撤销与光标、格式作用范围、概要和外框独立操作。

## 标题编辑

标题采用受控数据模型和 contenteditable 原位编辑，输入区直接呈现文字格式，不再以 textarea 加独立预览代替。保留 200 UTF-16 单位上限，截断不拆开代理对。HTML 不进入标题数据；粘贴只接受纯文本，渲染通过 textContent 和安全 span 完成。Shift+Enter 插入换行，Enter 确认，Tab 沿用已有创建链，Esc 取消。

格式按钮按“全图/层级/节点默认 + 局部文字覆盖”计算最终值：继承的粗体可直接取消，颜色和字号回显实际值，混合选区显示 mixed。光标位于格式边界时继承左侧文字，开头取首字符。光标处可切换后续输入的粗斜体、字号、颜色。选择文字后清除格式只清该选区；未选择文字时恢复整个标题的默认格式和对齐。

标题局部编辑独立于持久画布历史。连续键入、连续同方向删除在选区连续且 1 秒内合并；粘贴、换行、中文组合输入和格式修改各算一步。保存前、撤销前记录光标与选区方向；撤销、重做恢复文字、格式、光标和选区。Alt/Option+F10 可从标题进入文字格式工具栏，按钮间可用方向键和 Home/End 导航，原有 Tab 创建子主题语义保留。格式控件获得键盘焦点后也支持编辑内撤销重做和 Esc。Mac ⌘Z/⇧⌘Z，Windows Ctrl+Z/Ctrl+Y/Ctrl+Shift+Z；粗斜体使用 ⌘/Ctrl+B、I。组合输入期间不重绘 DOM、不触发画布快捷键，结束时作为一次变更提交。

继续沿用标题与 title_format 同事务提交、回执核对、版本保护、输入期间保存不丢草稿，以及账号/企业草稿隔离。确认后整次操作进入画布撤销重做。

## 格式作用范围

- 编辑中的选区：只修改选中文字，未指定的属性继续继承。
- 样式面板：外观调整保留局部文字格式；明确操作某个文字属性时，清除该属性在标题内的局部覆盖。对齐控件对整标题生效，多选显示混合状态，未修改对齐时保留各节点的原对齐。
- 多选主题：可一次批量设置左/中/右对齐，保留各自备注、附件和文字范围。
- 格式刷/复制粘贴样式：复制节点样式与标题对齐，目标标题文字统一采用来源节点的默认文字样式，不复制来源文字、局部文字范围、备注、媒体。
- 恢复默认样式：同时移除节点显式样式、局部文字格式和显式对齐，重新采用层级/全图默认；保留内容资料。

这些操作复用 update_canvas_data 及其原子布局与历史。格式或对齐变化使用实际渲染尺寸参与结构重排。

## 独立概要与外框

单击概要括号或外框/外框名称只选中该元素；只有选中元素显示范围控点。双击/Space/F2/Enter 编辑名称，独立操作条和右键菜单可编辑范围或删除，Esc 取消选择。删除外框只移除该外框；删除概要只删除概要主题及其子分支，原被汇总分支不变。只读模式可选中，但不能修改或删除。

新增外框采用 `canvas_data.boundaries: [{id: UUID, title, members}]`，最多 100 个/承载节点，并受既有 64 KiB 数据限制。每个外框独立标识，新增追加而非覆盖。旧 `boundary` 保留读取/编辑能力，不做破坏性转换。同起点外框错开标题与边框，范围控点和适配全图包含相应外扩。

新迁移 325 扩展严格数据验证和同事务命令：

- 外框成员须属于当前容器、可见、同一非空父节点；非法身份、重复 ID、跨空间、旧版本拒绝并回滚。
- 固定复制快照重建外框 ID，成员全部指向副本；只复制部分范围时不保留不完整外框，避免引用原数据。
- 插入父主题时迁移承载数据并重映射范围；只删当前主题时映射到被提升子主题。
- 删除分支或调整层级时保留原范围的存活成员，必要时迁移承载节点，避免外框因存储节点变化消失。
- 快照与撤销恢复完整元数据；撤销恢复外框时重新选中该外框。容器/节点版本、写权限、幂等回执和历史限制继续有效。

既有 305–324 未修改。本轮迁移仅在一次性 loopback PostgreSQL 验证，未应用生产。
