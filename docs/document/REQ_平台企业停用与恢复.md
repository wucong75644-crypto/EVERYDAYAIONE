# 平台企业停用与恢复需求

## 已确认范围

- active super_admin 可在平台企业列表停用 active 企业、恢复 suspended 企业。
- 状态转换、前后状态审计在同一数据库事务完成；并发只允许一次转换成功。
- suspended 企业不得登录、建立企业上下文、接受邀请、消费配置或被 Runtime、Worker、
  WeCom、Sync、Agent 执行链继续发现和处理。
- 企业、成员、邀请、配置、Secret、文件、消息、任务和审计数据全部保留。
- 恢复不改变成员、配置、Secret 或历史任务状态。

## 明确排除

- 企业物理删除及删除入口。
- 自动恢复 disabled 成员或 revoked/expired Secret。
- 撤销已发送且外部提供商不支持取消的请求。

## 验收

数据库必须验证权限矩阵、原子状态转换、审计事务、并发冲突和对称回滚；API 必须保持
平台 Scope 并返回稳定安全错误；前端必须按权威状态显示唯一操作、停用名称确认、请求
取消与成功后重新读取列表。
